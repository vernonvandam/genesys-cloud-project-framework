# 09.02 — Project Estimate

## Purpose

Define the consolidated project effort estimate.

## Required Content

The project estimate shall include:

- total delivery effort;
- total customer effort;
- total effort by role;
- total effort by phase;
- total effort by workstream;
- contingency;
- optional scope;
- conditional scope;
- assumptions;
- confidence level.

## Calculation

```text
Baseline Effort
+ Approved Adjustment
+ Approved Contingency
= Project Estimate
```

## Controls

The project estimate must be generated from approved task records and must not contain untraceable manual effort.

## Acceptance Criteria

- All included tasks are traceable.
- Effort totals reconcile.
- Contingency is separately identified.
- Customer effort is separated.
- Scenario is identified.
- Estimate has an approval status.
