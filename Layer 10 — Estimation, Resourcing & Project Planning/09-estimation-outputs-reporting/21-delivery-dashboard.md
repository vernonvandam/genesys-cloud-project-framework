# 09.21 — Delivery Dashboard

## Purpose

Provide an operational view of project delivery status.

## Dashboard Metrics

- tasks planned;
- tasks complete;
- tasks in progress;
- tasks blocked;
- effort planned;
- effort consumed;
- effort remaining;
- schedule variance;
- critical-path status;
- milestone status;
- risk status;
- dependency status.

## Acceptance Criteria

Dashboard calculations are sourced from controlled project data.
