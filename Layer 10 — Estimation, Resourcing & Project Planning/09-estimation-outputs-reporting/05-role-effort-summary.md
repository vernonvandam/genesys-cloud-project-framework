# 09.05 — Role Effort Summary

## Purpose

Provide effort totals by delivery role.

## Standard Dimensions

- Project Manager
- Solution Architect
- Technical Architect
- Genesys Cloud Architect
- Genesys Cloud Engineer
- Voice / Telephony Engineer
- Integration Engineer
- Data Engineer
- WFM Specialist
- Quality Specialist
- Reporting Specialist
- Security Specialist
- Tester
- Trainer
- Service Manager

## Required Outputs

| Metric | Requirement |
|---|---|
| Task Count | Required |
| Hours | Required |
| Percentage | Required |
| Peak Period | Required |
| Customer / Delivery | Required |

## Acceptance Criteria

Every task with assigned delivery effort has a valid role mapping.
