# 09.19 — Estimation Comparison

## Purpose

Compare estimates across versions, scenarios or project baselines.

## Comparison Metrics

- total effort;
- task count;
- role effort;
- phase effort;
- schedule duration;
- critical path;
- customer effort;
- contingency;
- material changes.

## Required Change Categories

- Added task
- Removed task
- Effort changed
- Role changed
- Dependency changed
- Scope classification changed
- Assumption changed

## Acceptance Criteria

Estimate changes are explainable and traceable to source changes.
