# 09.12 — Project Schedule Output

## Purpose

Define the standard project schedule generated from the task catalogue.

## Required Columns

| Field | Requirement |
|---|---|
| Task ID | Required |
| Phase | Required |
| Workstream | Required |
| Task | Required |
| Role | Required |
| Dependency | Required |
| Start | Required |
| Finish | Required |
| Duration | Required |
| Effort | Required |
| Critical Path | Required |
| Customer Responsibility | Required |
| Status | Required |

## Acceptance Criteria

The schedule is generated from the approved task model and remains traceable to source tasks.
