# 09.15 — Assumption Register Output

## Purpose

Expose assumptions that materially influence the estimate or schedule.

## Required Fields

| Field | Requirement |
|---|---|
| Assumption ID | Required |
| Description | Required |
| Source | Required |
| Impact | Required |
| Owner | Required |
| Status | Required |
| Related Tasks | Required |
| Estimate Impact | Required |

## Controls

Changes to material assumptions shall trigger estimation review.

## Acceptance Criteria

All material assumptions affecting the estimate are recorded and assigned.
