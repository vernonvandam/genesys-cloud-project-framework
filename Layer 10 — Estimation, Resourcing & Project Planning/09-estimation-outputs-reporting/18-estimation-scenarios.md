# 09.18 — Estimation Scenarios

## Purpose

Allow project estimates to be evaluated under different delivery assumptions.

## Standard Scenarios

- Lean
- Baseline
- Conservative
- Complex
- Customer-specific

## Scenario Dimensions

Scenarios may vary:

- task inclusion;
- effort multipliers;
- contingency;
- resource availability;
- delivery duration;
- migration approach;
- integration complexity;
- customer readiness.

## Acceptance Criteria

Scenario calculations use the same underlying task catalogue and clearly identify changed assumptions.
