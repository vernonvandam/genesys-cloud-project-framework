# 09.11 — Critical Path Analysis

## Purpose

Identify tasks and dependencies that directly influence project completion.

## Method

```text
Tasks
  ↓
Dependencies
  ↓
Duration
  ↓
Network Analysis
  ↓
Critical Path
  ↓
Project Completion Date
```

## Required Outputs

- critical tasks;
- critical dependencies;
- float;
- critical milestones;
- critical workstreams;
- critical roles.

## Acceptance Criteria

The calculated critical path reconciles with the project schedule.
