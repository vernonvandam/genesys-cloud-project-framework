# 09.13 — Milestone Output

## Purpose

Define project milestones derived from schedule and delivery dependencies.

## Typical Milestones

- Requirements Approved
- Architecture Approved
- Build Complete
- Integration Complete
- SIT Complete
- UAT Complete
- Migration Ready
- Cutover Approved
- Production Go-Live
- Hypercare Complete
- Operational Handover
- Project Closure

## Acceptance Criteria

Every milestone has:

- owner;
- target date;
- prerequisite tasks;
- acceptance criteria;
- approval authority.
