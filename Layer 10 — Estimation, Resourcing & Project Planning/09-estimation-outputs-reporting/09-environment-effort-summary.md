# 09.09 — Environment Effort Summary

## Purpose

Summarise effort by delivery environment.

## Environments

- DESIGN
- DEV
- TEST
- UAT
- PROD
- MULTI

## Required Outputs

- task count;
- effort;
- role effort;
- customer effort;
- environment transition dependencies.

## Acceptance Criteria

Environment totals reconcile to the task catalogue.
