# 09.23 — Resource Capacity Reporting

## Purpose

Compare forecast resource demand with available delivery capacity.

## Required Metrics

```text
Required Capacity
Available Capacity
Capacity Gap
Utilisation
Peak Demand
Over-allocation
Under-utilisation
```

## Required Dimensions

- role;
- period;
- workstream;
- project;
- resource.

## Acceptance Criteria

Capacity gaps are visible before they create schedule risk.
