# 09.04 — Resource Summary

## Purpose

Define resource demand across the project lifecycle.

## Required Information

- role;
- required hours;
- required FTE;
- start period;
- end period;
- peak demand;
- concurrent demand;
- allocation assumptions.

## Resource Model

```text
Task Effort
    ↓
Role Assignment
    ↓
Schedule Timing
    ↓
Periodised Resource Demand
    ↓
Capacity Comparison
```

## Acceptance Criteria

Resource demand reconciles to task effort and identifies periods of over-allocation.
