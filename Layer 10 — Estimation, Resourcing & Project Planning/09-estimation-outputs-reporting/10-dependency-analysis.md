# 09.10 — Dependency Analysis

## Purpose

Provide a structured view of dependencies affecting delivery.

## Dependency Types

- task-to-task;
- capability-to-capability;
- phase-to-phase;
- customer dependency;
- external dependency;
- technical dependency;
- approval dependency;
- environment dependency.

## Required Analysis

Identify:

- dependency count;
- unresolved dependencies;
- blocking dependencies;
- external dependencies;
- customer dependencies;
- dependency chains.

## Acceptance Criteria

All mandatory task dependencies are represented in the dependency model.
