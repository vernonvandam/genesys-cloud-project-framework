# Layer 10 — 2.15.50 Platform Lifecycle Management

## Capability Reference

| Attribute | Value |

## Capability Objective

Govern the lifecycle of the Genesys Cloud platform from ongoing optimisation through feature adoption, architecture evolution, retirement and future-state planning.

## Layer 1 Mapping

| Phase | Application |
|---|---|
| P02 | Assess lifecycle state |
| P03 | Define lifecycle requirements |
| P04 | Define lifecycle strategy |
| P09 | Govern platform lifecycle |
| P12 | Maintain ongoing lifecycle ownership |

## Source Implementation Activities

1. Assess platform lifecycle state.
2. Identify lifecycle risks.
3. Define lifecycle strategy.
4. Manage platform evolution.
5. Manage retirement and replacement.
