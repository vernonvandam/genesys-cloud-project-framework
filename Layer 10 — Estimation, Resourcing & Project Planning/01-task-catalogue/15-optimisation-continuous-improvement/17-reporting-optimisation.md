## Capability Objective

Optimise operational, management and executive reporting to improve decision quality, consistency, usability and efficiency.

## Layer 1 Mapping

| Phase | Application |
|---|---|
| P02 | Assess report estate |
| P03 | Define reporting improvements |
| P04 | Design target reporting |
| P06 | Implement changes |
| P08 | Validate reports |
| P09 | Operationalise reporting |

## Source Implementation Activities

1. Assess reporting estate.
2. Identify redundant or ineffective reports.
3. Improve report definitions.
4. Optimise dashboards and distribution.
5. Validate reporting outcomes.
