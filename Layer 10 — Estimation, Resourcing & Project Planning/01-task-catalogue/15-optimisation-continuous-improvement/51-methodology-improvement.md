# Layer 10 — 2.15.51 Methodology Improvement

## Capability Reference

| Attribute | Value |
|---|---|
| Layer | Layer 10 — Estimation, Resourcing & Project Planning |
| Domain | 15 — Optimisation, Continuous Improvement & Platform Evolution |
| Capability ID | 2.15.51 |

| Task Catalogue ID | 15.51 |

## Capability Objective

Continuously improve the Genesys Cloud deployment methodology itself using project experience, lessons learned, delivery metrics, estimation accuracy and customer feedback.

## Layer 1 Mapping

| Phase | Application |
|---|---|
| P08 | Identify methodology issues during delivery |
| P09 | Analyse operational and delivery performance |
| P12 | Update methodology and standards |

## Source Implementation Activities

1. Capture methodology feedback.
2. Analyse delivery performance.
3. Identify methodology improvements.
4. Update templates and standards.
5. Govern methodology changes.

## Capability-Level Estimation Considerations

Effort is influenced by:

- number of lessons
- number of methodology assets affected
- number of projects contributing data
- estimation model complexity
- number of task catalogue changes
- governance requirements
- approval cycles

## Definition of Done

The methodology improvement capability is:

- collecting evidence
- measuring delivery performance
- identifying improvements
- maintaining a governed improvement backlog
- updating methodology assets
- version controlled
- approved
- feeding improvements back into future projects
