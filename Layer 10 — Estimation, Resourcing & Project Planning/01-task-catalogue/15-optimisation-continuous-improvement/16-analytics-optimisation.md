## Capability Objective

Improve the usefulness, accuracy, timeliness, performance and governance of Genesys Cloud analytics.

## Layer 1 Mapping

| Phase | Application |
|---|---|
| P02 | Assess analytics estate |
| P03 | Define analytics improvement requirements |
| P04 | Design analytics improvements |
| P06 | Implement changes |
| P08 | Validate analytics |
| P09 | Operationalise analytics |

## Source Implementation Activities

1. Assess analytics usage and quality.
2. Identify analytics gaps.
3. Improve data and metric definitions.
4. Optimise analytics configuration.
5. Validate outcomes.
