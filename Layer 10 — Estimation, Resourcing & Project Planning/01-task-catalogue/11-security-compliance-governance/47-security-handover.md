| Phase | Application |

1. Prepare security handover.
2. Complete operational documentation.
3. Transfer security ownership.
4. Obtain handover acceptance.

- Compliance testing

## Capability-Level Estimation Considerations

Effort varies with:

- number of operational teams
- number of security controls
- regulatory evidence requirements
- documentation maturity
- customer governance processes
- handover complexity

## Definition of Done

Security ownership has formally transitioned to BAU and all required security documentation, evidence, controls and outstanding actions have been accepted.
