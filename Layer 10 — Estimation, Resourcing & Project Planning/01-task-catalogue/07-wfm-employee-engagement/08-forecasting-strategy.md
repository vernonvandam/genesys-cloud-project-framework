## Capability Objective

Define the forecasting approach, assumptions, ownership, horizon and validation model.

## Source Implementation Activities

1. Assess forecasting requirements.
2. Define forecast horizons and methodology.
3. Define assumptions.
4. Establish forecast governance.
5. Validate forecast strategy.
