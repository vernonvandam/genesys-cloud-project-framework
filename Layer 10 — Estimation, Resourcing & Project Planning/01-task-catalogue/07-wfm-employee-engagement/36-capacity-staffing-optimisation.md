# Layer 10 — 2.07.36 Capacity & Staffing Optimisation

## Capability Reference

| Attribute | Value |
|---|---|

| Capability ID | 2.07.36 |
| Capability | Capacity & Staffing Optimisation |
| Task Catalogue ID | 07.36 |
| Primary Layer 1 Phases | P03, P04, P06, P08, P11, P12 |

## Capability Objective

Optimise workforce capacity and staffing levels against demand, service goals and operational constraints.

## Source Implementation Activities

1. Establish optimisation objectives.
2. Assess staffing gaps.
3. Model capacity options.
4. Implement optimisation changes.
5. Measure outcomes.
