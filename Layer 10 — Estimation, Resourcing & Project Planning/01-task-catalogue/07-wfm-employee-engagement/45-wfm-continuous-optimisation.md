# Layer 10 — 2.07.45 WFM Continuous Optimisation

## Capability Reference

| Attribute | Value |
|---|---|

| Capability | WFM Continuous Optimisation |
| Task Catalogue ID | 07.45 |
| Primary Layer 1 Phases | P11, P12 |

## Capability Objective

Establish the continuous improvement cycle required to maintain forecast accuracy, staffing effectiveness, employee experience and operational performance.

## Source Implementation Activities

1. Establish WFM optimisation objectives.
2. Measure performance.
3. Identify improvement opportunities.
4. Implement optimisation changes.
5. Measure outcomes.
6. Establish recurring optimisation governance.

## Capability-Level Dependencies

- WFM reporting
- WFM governance
- WFM operations
- Forecasting
- Staffing
- Scheduling
- Adherence
- Employee experience

## Capability-Level Estimation Considerations

Effort is influenced by:

- optimisation frequency
- number of workforce populations
- KPI complexity
- forecast variance
- operational maturity
- number of improvement initiatives
- reporting complexity
- governance requirements

## Definition of Done

Continuous optimisation is established when:

- WFM KPIs are defined.
- Production baseline is documented.
- Optimisation opportunities are identified.
- Improvement backlog is prioritised.
- Optimisation roadmap is approved.
- Recurring governance is established.
- BAU ownership is accepted.
