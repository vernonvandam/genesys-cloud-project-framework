# Layer 10 — 2.07.02 WFM Strategy & Governance

## Capability Reference

| Attribute | Value |
|---|---|
| Layer | Layer 10 — Estimation, Resourcing & Project Planning |
| Domain | 07 — Workforce Management & Employee Engagement |
| Capability ID | 2.07.02 |

| Task Catalogue ID | 07.02 |

## Capability Objective

Define how workforce management will be governed, operated, measured and continuously improved.

## Layer 1 Mapping

| Phase | Application |
|---|---|
| P01 | Establish governance ownership |
| P02 | Assess current WFM operating model |
| P03 | Define WFM governance requirements |
| P04 | Design WFM operating model |
| P09 | Prepare BAU governance |
| P12 | Handover governance |

## Source Implementation Activities

1. Establish WFM governance scope.
2. Define WFM roles and decision rights.
3. Define operational governance.
4. Define KPI ownership and review cadence.
5. Establish BAU governance.
