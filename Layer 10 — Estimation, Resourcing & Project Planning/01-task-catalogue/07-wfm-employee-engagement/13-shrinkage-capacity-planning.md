# Layer 10 — 2.07.13 Shrinkage & Capacity Planning

## Capability Reference

| Attribute | Value |
|---|---|
| Layer | Layer 10 — Estimation, Resourcing & Project Planning |
| Domain | 07 — Workforce Management & Employee Engagement |
| Capability ID | 2.07.13 |
| Capability | Shrinkage & Capacity Planning |
| Task Catalogue ID | 07.13 |
| Primary Layer 1 Phases | P03, P04, P06, P08, P11 |

## Capability Objective

Model shrinkage and capacity constraints so staffing plans represent realistic workforce availability.

## Source Implementation Activities

1. Identify shrinkage categories.
2. Define shrinkage assumptions.
3. Calculate effective capacity.
4. Validate staffing impact.
5. Establish ongoing review.
