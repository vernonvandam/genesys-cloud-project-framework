## Task ID Standard

Tasks use the Layer 10 standard:

`L10-DD.CC-TTT`

Where:

- `DD` = Layer 2 domain
- `CC` = capability number
- `TTT` = sequential implementation task

Example:

`L10-10.05-001`

## Layer 1 Phase Usage

Quality, recording and evaluation capabilities may span:

- **P01** — Initiation and Scope
- **P02** — Discovery and Current State
- **P03** — Requirements
- **P04** — Solution Design
- **P05** — Build and Configuration
- **P06** — Integration and Technical Enablement
- **P07** — Migration and Data Transition
- **P08** — System Testing and Validation
- **P09** — User Acceptance and Operational Validation
- **P10** — Production Readiness and Cutover
- **P11** — Hypercare and Stabilisation
- **P12** — Operational Handover and Closure

## Task Classification

Tasks use:

- `REQUIRED`
- `CONDITIONAL`
- `OPTIONAL`
- `VALIDATION`

## Definition of Done

A capability is complete when:

- requirements are confirmed
- design is approved where applicable
- configuration is implemented
- dependencies are resolved
- testing and validation are completed
- customer acceptance criteria are satisfied
- required documentation is complete
- operational ownership is established
- production readiness or handover requirements are satisfied
