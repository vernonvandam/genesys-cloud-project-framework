## Capability Reference

| Attribute | Value |

## Capability Objective

Establish governance, ownership, decision rights, review processes and escalation paths for quality management.

## Layer 1 Mapping

| Phase | Application |
|---|---|
| P01 | Identify governance stakeholders |
| P03 | Define governance requirements |
| P04 | Design governance model |
| P09 | Validate governance processes |
| P12 | Transfer governance ownership |

## Source Implementation Activities

1. Identify quality governance stakeholders.
2. Define decision rights.
3. Define review and escalation processes.
4. Establish governance ownership.
