| Attribute | Value |

## Capability Objective

Define the customer quality management strategy, operating model, objectives, governance, KPIs, and ownership.

## Layer 1 Mapping

| Phase | Application |
|---|---|
| P01 | Establish quality scope and stakeholders |
| P02 | Assess current quality processes |
| P03 | Define quality requirements |
| P04 | Design target quality operating model |
| P09 | Validate quality operating model |
| P12 | Handover quality governance |

## Source Implementation Activities

1. Define quality objectives.
2. Define quality operating model.
3. Define quality KPIs.
4. Obtain stakeholder approval.
