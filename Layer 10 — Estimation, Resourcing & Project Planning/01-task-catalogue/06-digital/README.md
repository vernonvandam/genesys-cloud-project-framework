# Layer 10 — 06 Digital Task Catalogue

## Purpose

This directory contains the implementation task catalogue for **Layer 2 — 06 Digital**.

The catalogue translates the Digital capability model into implementation-level tasks that can be used to:

- develop project schedules
- estimate implementation effort
- assign delivery responsibilities
- identify dependencies
- establish critical paths
- define deliverables
- establish acceptance criteria
- support implementation planning
- support project governance
- populate the Layer 10 spreadsheet model

## Task ID Convention

```text
L10-06.<capability>.<task>
```

Example:

```text
L10-06.03-001
```

Where:

- `L10` = Layer 10
- `06` = Digital domain
- `03` = Digital capability number
- `001` = sequential implementation task

## Task Classification

Tasks use the following classifications:

- `REQUIRED` — expected for applicable implementations
- `CONDITIONAL` — required only when the capability or scenario applies
- `OPTIONAL` — implementation enhancement
- `VALIDATION` — verification or acceptance activity

## Environment Values

Tasks use:

- `DESIGN`
- `DEV`
- `TEST`
- `UAT`
- `PROD`
- `MULTI`

## Completion Standard

Every capability should be:

- designed
- configured where applicable
- integrated where applicable
- tested
- accepted
- documented
- operationally supported
