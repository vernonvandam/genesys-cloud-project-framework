# Layer 10 — 2.06.30 Digital Security & Privacy

## Capability Objective

Protect digital customer interactions and personal information through appropriate security and privacy controls.

| Attribute | Value |
|---|---|
| Task Type | REQUIRED |
| Layer 1 Phase | P03 |
| Primary Role | Security Architect |
| Customer Responsibility | JOINT |
| Environment | DESIGN |
| Automation | MANUAL |
| Baseline Effort | 4.0h |
| Critical Path | YES |

**Description**

Assess authentication, PII, attachments, integrations, access, retention and channel-specific risks.
