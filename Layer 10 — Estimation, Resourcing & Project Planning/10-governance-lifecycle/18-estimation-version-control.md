# Layer 10 — 10.18 Estimation Version Control

## Capability Reference

| Attribute | Value |
|---|---|
| Layer | Layer 10 — Estimation, Resourcing & Project Planning |
| Domain | 10 — Governance & Lifecycle |
| Capability ID | 10.18 |
| Capability | Estimation Version Control |
| Task Catalogue ID | 10.18 |
| Primary Layer 1 Phases | P04, P09, P11, P12 |

## Capability Objective

Maintain controlled versions of estimates and preserve historical traceability.

## Layer 1 Mapping

| Phase | Application |
|---|---|
| P04 | Establish versioning |
| P09 | Baseline estimate version |
| P11 | Maintain forecast versions |
| P12 | Archive final versions |

## Source Implementation Activities

1. Define version standard.
2. Assign estimate versions.
3. Record changes.
4. Archive historical versions.
