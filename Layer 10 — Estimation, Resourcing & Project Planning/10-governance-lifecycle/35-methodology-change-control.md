## Capability Objective

Control changes to the master Genesys Cloud Deployment Methodology.

## Layer 1 Mapping

| Phase | Application |
|---|---|
| P12 | Review, approve and release methodology changes |

## Source Implementation Activities

1. Identify change.
2. Assess impact.
3. Review change.
4. Approve change.
5. Implement and validate.
