# Layer 10 — 10.31 Estimation Confidence Review

## Capability Reference

| Attribute | Value |
|---|---|
| Layer | Layer 10 — Estimation, Resourcing & Project Planning |
| Domain | 10 — Governance & Lifecycle |

| Capability | Estimation Confidence Review |
| Task Catalogue ID | 10.31 |

## Capability Objective

Assess and maintain confidence in project estimates as information maturity changes.

## Layer 1 Mapping

| Phase | Application |
|---|---|
| P03 | Establish initial confidence |
| P09 | Confirm baseline confidence |
| P11 | Reassess confidence during delivery |

## Source Implementation Activities

1. Define confidence criteria.
2. Assess confidence.
3. Identify confidence drivers.
4. Reassess confidence.
