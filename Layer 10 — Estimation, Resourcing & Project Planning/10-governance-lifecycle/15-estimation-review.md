## Capability Reference

| Attribute | Value |
|---|---|
| Layer | Layer 10 — Estimation, Resourcing & Project Planning |

| Task Catalogue ID | 10.15 |

## Capability Objective

Provide a formal review of estimate completeness, quality, assumptions, dependencies and confidence.

## Layer 1 Mapping

| Phase | Application |
|---|---|
| P03 | Define review criteria |
| P04 | Perform technical review |
| P09 | Complete baseline review |

## Source Implementation Activities

1. Define review criteria.
2. Review estimate.
3. Record findings.
4. Resolve findings.
5. Complete review.
