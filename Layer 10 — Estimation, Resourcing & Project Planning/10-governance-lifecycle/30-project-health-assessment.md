# Layer 10 — 10.30 Project Health Assessment

## Capability Reference

| Attribute | Value |
|---|---|
| Layer | Layer 10 — Estimation, Resourcing & Project Planning |

| Capability | Project Health Assessment |
| Task Catalogue ID | 10.30 |

## Capability Objective

Provide a consistent assessment of project health across scope, schedule, effort, resources, risks and readiness.

## Layer 1 Mapping

| Phase | Application |
|---|---|
| P09 | Establish baseline health |
| P11 | Monitor health during hypercare |

## Source Implementation Activities

1. Define health criteria.
2. Assess project health.
3. Record status.
4. Identify corrective action.
