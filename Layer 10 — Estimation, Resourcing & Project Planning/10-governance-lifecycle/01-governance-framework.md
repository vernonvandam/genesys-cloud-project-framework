## Capability Objective

Establish the governance structure, ownership, decision rights and control framework for the deployment methodology.

## Layer 1 Mapping

| Phase | Application |
|---|---|
| P01 | Establish governance ownership |
| P03 | Define governance requirements |
| P04 | Design governance framework |
| P12 | Review and close governance obligations |

## Source Implementation Activities

1. Establish governance ownership.
2. Define governance requirements.
3. Design governance framework.
4. Establish decision and escalation paths.
5. Validate governance controls.
6. Document governance model.
