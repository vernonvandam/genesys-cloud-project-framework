# Layer 10 — 10.16 Estimation Approval

## Capability Reference

| Attribute | Value |
|---|---|
| Layer | Layer 10 — Estimation, Resourcing & Project Planning |

| Capability | Estimation Approval |
| Task Catalogue ID | 10.16 |
| Primary Layer 1 Phases | P09, P10 |

## Capability Objective

Obtain formal approval of the project estimate before it becomes the controlled baseline.

## Layer 1 Mapping

| Phase | Application |
|---|---|
| P09 | Obtain estimate approval |
| P10 | Confirm approved estimate remains valid for deployment |

## Source Implementation Activities

1. Prepare approval pack.
2. Present estimate.
3. Record approval.
4. Apply conditions.
5. Confirm baseline readiness.
