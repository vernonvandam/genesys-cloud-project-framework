## Capability Objective

Govern project performance against approved scope, effort, schedule, quality and resource baselines.

## Layer 1 Mapping

| Phase | Application |
|---|---|
| P06 | Monitor delivery performance |
| P09 | Establish performance baseline |
| P11 | Monitor performance during hypercare |

## Source Implementation Activities

1. Define performance measures.
2. Establish baseline measures.
3. Monitor performance.
4. Analyse deviations.
5. Escalate issues.
