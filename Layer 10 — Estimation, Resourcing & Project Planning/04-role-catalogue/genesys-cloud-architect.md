# Genesys Cloud Architect

## Role ID

```text
GCA
```

## Role Name

Genesys Cloud Architect

## Purpose

The Genesys Cloud Architect is responsible for designing and implementing Genesys Cloud platform capabilities in accordance with approved business, technical, security and operational requirements.

---

# 1. Primary Responsibilities

The role is responsible for:

- Genesys Cloud solution design
- platform architecture
- Genesys Cloud configuration strategy
- Architect design
- routing design
- telephony design
- digital design
- platform integration design
- platform security design
- configuration standards
- implementation guidance
- technical validation
