# Integration Engineer

## Role ID

```text
IE
```

## Role Name

Integration Engineer

## Purpose

The Integration Engineer designs, develops, configures, tests and validates integrations between Genesys Cloud and external systems.

---

# 1. Primary Responsibilities

The role performs:

- API integration
- data exchange design
- Data Actions
- web services
- authentication integration
- middleware integration
- event integration
- integration testing
- error handling
- integration monitoring
- integration documentation

The task is complete when:

- integration is configured or implemented
- connectivity is validated
- required authentication is working
- data mapping is validated
- error handling is tested
- acceptance criteria are satisfied
- documentation is complete
