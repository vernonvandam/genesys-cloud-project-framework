# Genesys Cloud Engineer

## Role ID

```text
GCE
```

## Role Name

Genesys Cloud Engineer

## Purpose

The Genesys Cloud Engineer performs the detailed configuration, implementation, validation and technical administration of Genesys Cloud capabilities.

---

# 1. Primary Responsibilities

The role performs:

- Genesys Cloud configuration
- queue configuration
- user configuration
- routing configuration
- Architect configuration
- telephony configuration
- digital configuration
- permissions
- platform administration
- configuration validation
- deployment support
- defect remediation
