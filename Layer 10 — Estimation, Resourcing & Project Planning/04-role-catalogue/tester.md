# Tester

## Role ID

```text
TEST
```

## Role Name

Tester

## Purpose

The Tester provides independent quality assurance through test planning, test execution, defect validation, regression testing and evidence management.

---

# 1. Primary Responsibilities

The role performs:

- test planning
- test scenario design
- test case creation
- test data coordination
- functional testing
- integration testing
- regression testing
- defect management
- defect retesting
- test evidence
- test reporting
- release validation

# 8. Definition of Done

The testing task is complete when:

- planned tests have been executed
- defects are recorded
- defects requiring resolution are retested
- test evidence is captured
- acceptance criteria are satisfied
- test status is reported
- required sign-off is obtained
