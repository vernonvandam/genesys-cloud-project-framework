# Solution Architect

## Role ID

```text
SA
```

## Role Name

Solution Architect

## Purpose

The Solution Architect provides end-to-end solution design authority across Genesys Cloud, surrounding systems, business processes, security, data, integrations and operational requirements.

---

# 1. Primary Responsibilities

The role performs:

- solution architecture
- end-to-end design
- architecture decisions
- cross-domain design
- non-functional requirements
- integration architecture
- security architecture coordination
- migration architecture
- operational architecture
- design governance
