# Project Manager

## Role ID

```text
PM
```

## Role Name

Project Manager

## Purpose

The Project Manager provides governance, planning, coordination, risk management and delivery control across the Genesys Cloud implementation.

---

# 1. Primary Responsibilities

The role performs:

- project mobilisation
- planning
- schedule management
- dependency management
- risk management
- issue management
- status reporting
- stakeholder coordination
- change management
- governance
- milestone management
- cutover coordination
- handover coordination
- project closure

- milestones are tracked

- approvals are obtained
- project closure requirements are complete
