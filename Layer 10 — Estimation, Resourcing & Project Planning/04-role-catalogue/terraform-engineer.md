# Terraform Engineer

## Role ID

```text
TE
```

## Role Name

Terraform Engineer

## Purpose

The Terraform Engineer designs and implements infrastructure-as-code and automated deployment mechanisms for Genesys Cloud configuration and supporting infrastructure.

---

# 1. Primary Responsibilities

The role performs:

- Terraform architecture
- Terraform module development
- Genesys Cloud provider configuration
- infrastructure-as-code
- configuration automation
- deployment pipelines
- state management
- environment promotion
- automated validation
- source control integration
- deployment documentation
