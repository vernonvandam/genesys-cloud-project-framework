# Technical Architect

## Role ID

```text
TA
```

## Role Name

Technical Architect

## Purpose

The Technical Architect defines the technical architecture required to support the Genesys Cloud solution and its surrounding infrastructure, integrations, networking, security and deployment mechanisms.

---

# 1. Primary Responsibilities

The role performs:

- technical architecture
- infrastructure architecture
- network architecture
- connectivity
- integration architecture
- identity architecture
- security architecture support
- environment architecture
- deployment architecture
- technical standards
- non-functional technical requirements
