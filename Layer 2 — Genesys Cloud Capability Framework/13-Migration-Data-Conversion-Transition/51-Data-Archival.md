# Layer 2.13.51 — Data Archival

## Capability Definition

Data Archival preserves historical data that is not migrated into Genesys Cloud but must remain accessible for business, legal, regulatory or audit purposes.

---

# 1. Scope

- Historical interactions
- Recordings
- Reporting data
- Quality data
- WFM data
- Customer data
- Legal holds

---

# 2. Classification

**Conditional**

---

# 3. Discovery Activities

Identify data requiring long-term retention.

---

# 4. Design Activities

Define archive platform, access, retention, security, encryption and retrieval processes.
