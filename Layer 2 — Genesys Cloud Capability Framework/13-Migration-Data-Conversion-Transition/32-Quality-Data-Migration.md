# Layer 2.13.32 — Quality Data Migration

## Capability Definition

Quality Data Migration addresses preservation or migration of quality-management configuration, evaluations, scorecards and related historical data.

---

# 1. Scope

- Evaluation forms
- Evaluation results
- Scorecards
- Quality records
- Evaluator data
- Coaching history
- Quality reporting

---

# 2. Classification

**Conditional**

---

# 3. Discovery Activities

Identify historical quality data, retention and reporting requirements.

---

# 4. Design Activities

Determine what is migrated, recreated, archived or retired.
