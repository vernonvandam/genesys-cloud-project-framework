# Layer 2.13.09 — Data Retention

## Capability Definition

Data Retention defines how long source and migrated data must be retained and how retention affects migration, archival and decommissioning.

---

# 1. Scope

- Source retention
- Target retention
- Historical data
- Recordings
- Quality records
- Reporting data
- Legal holds
- Archival
- Deletion

---

# 2. Classification

**Required**

---

# 3. Discovery Activities

- Identify retention requirements.
- Identify regulatory retention periods.
- Identify legal holds.
- Identify data requiring historical access.

---

# 4. Design Activities

- Define archival approach.
- Define deletion controls.
- Define legacy retention requirements.
