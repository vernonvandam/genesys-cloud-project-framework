# Layer 2.07.01 — Workforce Management Architecture

## Purpose

Define the target-state architecture for Workforce Management and employee engagement.

## Classification

**Required**

## Activities

1. Inventory workforce processes.
2. Identify current WFM platforms.
3. Identify current workforce data sources.
4. Identify forecasting processes.
5. Identify scheduling processes.
6. Identify adherence processes.
7. Identify HR dependencies.
8. Identify payroll dependencies.
9. Define target WFM architecture.
10. Define integration architecture.
11. Define security architecture.
12. Define reporting architecture.
13. Obtain architecture approval.

## Deliverables

- WFM architecture
- Workforce operating model
- Integration architecture
- WFM dependency map

## Acceptance Criteria

All approved workforce capabilities and integrations are represented in the target architecture.

## Definition of Done

Architecture is approved by business, technical and operational stakeholders.
