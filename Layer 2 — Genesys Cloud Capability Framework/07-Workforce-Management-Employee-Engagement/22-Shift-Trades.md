# Layer 2.07.22 — Shift Trades

## Purpose

Allow agents to exchange schedules subject to approved controls.

## Classification

**Conditional**

## Activities

- Determine whether shift trading is required.
- Define eligibility.
- Define trade rules.
- Define skill requirements.
- Define supervisor approval.
- Configure.
- Test agent trade.
- Test invalid trade.
- Test approval.
- Validate schedule update.

## Acceptance Criteria

Shift trades do not create unacceptable staffing or skill gaps.

## Definition of Done

Shift trading is operational or formally excluded.
