# Layer 2.07.14 — Scheduling Strategy

## Purpose

Define how agents are scheduled to meet workforce requirements.

## Activities

- Define scheduling horizon.
- Define operating hours.
- Define shifts.
- Define breaks.
- Define activities.
- Define agent constraints.
- Define skills.
- Define time-off.
- Define employee preferences where applicable.
- Define schedule rules.
- Define optimisation priorities.

## Acceptance Criteria

Scheduling strategy balances operational requirements and employee constraints.

## Definition of Done

Scheduling strategy is approved.
