# Layer 2.07.17 — Schedule Generation

## Purpose

Generate agent schedules based on forecast staffing requirements and workforce constraints.

## Activities

- Select forecast.
- Select staffing requirement.
- Select management unit.
- Apply schedules rules.
- Apply time-off.
- Apply skills.
- Generate schedule.
- Review coverage.
- Identify gaps.
- Optimise.
- Approve.

## Acceptance Criteria

Generated schedules meet approved staffing requirements.

## Definition of Done

Schedules are generated and approved for publication.
