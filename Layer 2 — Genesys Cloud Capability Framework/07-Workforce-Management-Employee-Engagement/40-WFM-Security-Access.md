# Layer 2.07.40 — WFM Security & Access

## Purpose

Protect workforce data and enforce appropriate access.

## Classification

**Required**

## Scope

- WFM roles
- Planner access
- Supervisor access
- Agent access
- Reporting access
- Employee data
- Payroll information
- Performance data
- Audit

## Activities

- Identify WFM personas.
- Define role permissions.
- Apply least privilege.
- Configure permissions.
- Validate access.
- Test unauthorised access.
- Review audit requirements.

## Acceptance Criteria

Users can access only the workforce capabilities appropriate to their role.

## Definition of Done

Security approval is obtained.
