# Layer 2.07.37 — HR / HCM Integration

## Purpose

Integrate employee information from HR/HCM systems where required.

## Classification

**Conditional**

## Potential Data

- Employee ID
- Name
- Employment status
- Manager
- Organisation
- Location
- Skills
- Employment dates
- Work rules
- Availability

## Activities

- Identify source system.
- Define data ownership.
- Define employee identifier.
- Define field mapping.
- Define integration method.
- Configure.
- Test create.
- Test update.
- Test termination.
- Validate reconciliation.

## Acceptance Criteria

Employee data synchronises accurately.

## Definition of Done

HR integration is production-ready.
