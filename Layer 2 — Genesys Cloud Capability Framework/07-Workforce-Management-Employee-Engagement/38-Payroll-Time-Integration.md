# Layer 2.07.38 — Payroll & Time Integration

## Purpose

Integrate WFM schedule and time information with payroll/time systems where required.

## Classification

**Conditional**

## Activities

- Identify payroll system.
- Identify timekeeping system.
- Define data ownership.
- Define payable activities.
- Define time categories.
- Define export/import process.
- Configure integration.
- Validate data.
- Reconcile payroll periods.
- Test exceptions.

## Acceptance Criteria

Required workforce time data reconciles with payroll/time systems.

## Definition of Done

Payroll integration is operational.
