# Layer 2.07.23 — Agent Self-Service

## Purpose

Allow employees to manage appropriate workforce activities without supervisor intervention.

## Scope

- Schedule visibility
- Time-off requests
- Shift trades
- Schedule changes
- Notifications
- Workforce preferences

## Activities

- Define self-service scope.
- Define employee permissions.
- Configure access.
- Test agent experience.
- Test approval.
- Test notification.
- Validate mobile/web experience where applicable.

## Acceptance Criteria

Agents can perform approved workforce self-service activities.

## Definition of Done

Self-service is available and governed.
