# Layer 2.07.06 — Planning Groups

## Purpose

Define groups of workload that require forecasting and staffing.

## Classification

**Required**

## Activities

- Inventory queues.
- Inventory media types.
- Identify language requirements.
- Identify skill requirements.
- Identify workload types.
- Define planning groups.
- Map queues to planning groups.
- Validate historical data.
- Validate forecast requirements.

## Acceptance Criteria

All forecastable workloads are represented by an appropriate planning group.

## Definition of Done

Planning groups are approved.
