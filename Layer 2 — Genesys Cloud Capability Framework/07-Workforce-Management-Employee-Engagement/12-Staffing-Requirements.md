# Layer 2.07.12 — Staffing Requirements

## Purpose

Calculate the workforce required to meet forecast demand.

## Classification

**Required**

## Activities

- Define workload.
- Define service goals.
- Define occupancy.
- Define shrinkage.
- Define skill requirements.
- Calculate staffing.
- Review staffing gaps.
- Identify surplus.
- Validate against operational expectations.
- Approve staffing requirement.

## Acceptance Criteria

Required staffing is accurately represented for each planning period.

## Definition of Done

Staffing requirements are approved.
