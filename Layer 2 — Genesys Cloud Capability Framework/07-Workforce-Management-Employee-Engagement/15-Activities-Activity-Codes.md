# Layer 2.07.15 — Activities & Activity Codes

## Purpose

Define the activity types used in schedules and adherence.

## Examples

- Available
- Break
- Meal
- Training
- Meeting
- Coaching
- Administration
- Offline work
- Time off
- Other approved activities

## Activities

- Inventory current activities.
- Rationalise activities.
- Define activity names.
- Define activity categories.
- Define paid/unpaid behaviour where applicable.
- Define adherence treatment.
- Configure activities.
- Validate schedule impact.

## Acceptance Criteria

All required workforce activities are represented.

## Definition of Done

Activity catalogue is approved and configured.
