# Layer 2.07.24 — Intraday Management

## Purpose

Manage actual workforce conditions against the forecast during operational periods.

## Activities

- Define intraday roles.
- Define monitoring intervals.
- Define variance thresholds.
- Define escalation.
- Define corrective actions.
- Monitor workload.
- Monitor staffing.
- Monitor service level.
- Adjust schedules.
- Reallocate workforce.
- Document exceptions.

## Acceptance Criteria

Intraday managers can identify and respond to material workforce deviations.

## Definition of Done

Intraday operating process is documented and tested.
