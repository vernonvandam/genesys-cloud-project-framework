# Layer 2.07.21 — Time-Off Plans & Requests

## Purpose

Define time-off planning and employee request processes.

## Activities

- Define time-off planning periods.
- Define available capacity.
- Define request windows.
- Define approval workflow.
- Define supervisor responsibilities.
- Configure time-off plans.
- Test request.
- Test approval.
- Test schedule interaction.

## Acceptance Criteria

Time-off requests are managed consistently and do not compromise required staffing.

## Definition of Done

Time-off planning and request processes are operational.
