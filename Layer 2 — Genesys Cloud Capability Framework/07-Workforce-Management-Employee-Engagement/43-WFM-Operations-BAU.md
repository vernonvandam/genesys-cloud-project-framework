# Layer 2.07.43 — WFM Operations & BAU

## Purpose

Establish ongoing operational support for WFM.

## Scope

- Forecasting
- Scheduling
- Intraday management
- Adherence
- Time-off
- Shift trades
- Reporting
- Workforce data
- Integrations
- User support
- Configuration
- Change management

## Activities

- Define support ownership.
- Define WFM support tiers.
- Create runbooks.
- Define incident management.
- Define escalation.
- Define change management.
- Train WFM teams.
- Establish operating cadence.
- Establish KPI review.

## Deliverables

- WFM runbook
- Support matrix
- Escalation model
- Change process
- Troubleshooting guide

## Acceptance Criteria

BAU teams can operate the WFM environment without project-team dependency.

## Definition of Done

Operational handover is complete.
