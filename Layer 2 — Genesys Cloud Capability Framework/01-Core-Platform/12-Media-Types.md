# Layer 2.01.12 — Media Types

## Capability Definition

Defines which Genesys Cloud interaction media are in scope for the customer deployment.

---

# 1. Scope

Potential media types include:

- Voice
- Callback
- Email
- Messaging
- Chat where applicable
- Social messaging
- Other supported digital interaction types

The exact available media and functionality must be validated against the target Genesys Cloud release and licensing.

---

# 2. Classification

**Required**

Specific media types are conditional on project scope.

---

# 3. Discovery

Determine:

- Channels in scope.
- Existing channels.
- New channels.
- Channel volumes.
- Routing requirements.
- Recording requirements.
- Reporting requirements.
- Digital requirements.
- Integration requirements.

---

# 4. Implementation

```text
Confirm media scope
Confirm licensing
Define media architecture
Configure required media
Configure routing
Validate agent handling
Validate reporting
Validate recording where applicable
```

---

# 5. Layer 1 Mapping

Primary:

- Phase 3 — Requirements
- Phase 4 — Architecture
- Phase 6 — Solution Build

Supporting:

- Phase 8 — Testing

---

# 6. Acceptance Criteria

All approved media types are available and operate according to the approved design.

---

# 7. Definition of Done

Media scope is confirmed, configured, tested and documented.
