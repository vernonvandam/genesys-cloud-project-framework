# Layer 2.01.11 — Languages

## Capability Definition

Defines the languages required by the customer and how they affect Genesys Cloud capabilities.

---

# 1. Scope

- Agent languages
- Routing languages
- IVR languages
- Prompt languages
- Digital languages
- Bot languages
- Knowledge languages
- WFM implications
- Reporting implications

---

# 2. Classification

**Conditional**

Required for multilingual deployments.

---

# 3. Discovery

Determine:

- Supported customer languages.
- Agent languages.
- Language proficiency requirements.
- Routing requirements.
- IVR language requirements.
- Digital requirements.
- Bot requirements.
- Knowledge requirements.
- Translation requirements.

---

# 4. Implementation

```text
Identify supported languages
Define language naming
Map language to routing
Map language to agents
Configure applicable prompts
Configure applicable digital/bot capabilities
Validate multilingual behaviour
```

---

# 5. Dependencies

- Routing
- Architect
- Digital
- AI/Bots
- Knowledge
- WFM

---

# 6. Acceptance Criteria

Required languages are configured and correctly reflected in the solution design and routing behaviour.

---

# 7. Definition of Done

Language requirements are implemented and validated for all in-scope capabilities.
