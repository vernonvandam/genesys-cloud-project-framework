# Layer 2.01.14 — Licensing & Feature Entitlement

## Capability Definition

Defines the licensing and entitlement model required to support the selected Genesys Cloud solution.

---

# 1. Scope

- User licensing
- Feature licensing
- WEM licensing
- Digital licensing
- AI licensing
- Reporting/analytics entitlements
- Integration requirements
- Optional feature entitlements
- Licensing dependencies
- Consumption considerations

The exact licensing model must be validated against the customer's commercial agreement and the current Genesys Cloud product/licensing model.

---

# 2. Classification

**Required**

---

# 3. Discovery

Determine:

- Number of users.
- User types.
- Feature requirements.
- WEM requirements.
- QM requirements.
- Digital requirements.
- AI requirements.
- Integration requirements.
- Current licences.
- Required licences.
- Future growth.

---

# 4. Implementation

```text
Collect user counts
Classify user types
Map features to licensing
Identify gaps
Validate entitlements
Document licensing matrix
Confirm commercial approval
Validate platform access

```

# 5. Dependencies

- Requirements
- Capability selection
- Architecture
- Commercial agreement
- User model

---

# 6. Risks
- Capability unavailable under current licence.
- Incorrect user licence assignment.
- Future growth not considered.
- Commercial assumptions embedded in technical design.

---

# 7. Acceptance Criteria

All required capabilities have confirmed licensing/entitlement coverage.

---

# 8. Definition of Done

The licensing matrix is approved and all required platform capabilities can be implemented under the agreed commercial model.
