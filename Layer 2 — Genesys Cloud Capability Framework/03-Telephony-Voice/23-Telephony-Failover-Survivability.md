# Layer 2.03.23 — Telephony Failover & Survivability

## 1. Purpose

Define voice behaviour during failures of network, carrier, Genesys Cloud components or local infrastructure.

## 2. Classification

**Conditional**

## 3. Discovery

Determine:

- Required availability
- Network failure scenarios
- Carrier failure
- Site failure
- Edge failure
- Internet failure
- Endpoint failure
- Cloud service failure
- Business continuity requirements

## 4. Activities

- Define failure scenarios.
- Define expected behaviour.
- Design failover.
- Configure applicable controls.
- Test network failure.
- Test carrier failure.
- Test device failure.
- Test recovery.

## 5. Acceptance Criteria

All approved failure scenarios produce the documented expected outcome.

## 6. Definition of Done

Resilience and survivability requirements are tested and accepted.
