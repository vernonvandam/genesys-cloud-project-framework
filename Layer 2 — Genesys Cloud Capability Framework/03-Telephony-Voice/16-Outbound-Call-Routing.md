# Layer 2.03.16 — Outbound Call Routing

## 1. Purpose

Define how agents and applications place outbound calls to PSTN destinations.

## 2. Classification

**Required**

## 3. Discovery

Determine:

- Allowed destinations
- Calling line identity
- Carrier
- Number presentation
- International restrictions
- Premium-number restrictions
- Emergency calling
- Cost controls
- Recording requirements

## 4. Activities

- Define outbound routes.
- Define destination restrictions.
- Configure routes.
- Configure caller ID.
- Test local.
- Test national.
- Test international.
- Test restricted destinations.
- Test failure conditions.

## 5. Acceptance Criteria

Approved outbound destinations work and prohibited destinations are restricted.

## 6. Definition of Done

Outbound routing is configured and validated.
