# Layer 2.03.32 — Voice Operations & BAU

## 1. Purpose

Establish operational procedures for ongoing Genesys Cloud voice management.

## 2. Classification

**Required**

## 3. Scope

- Carrier support
- Number management
- User telephony
- Device management
- Voice-quality troubleshooting
- Incident management
- Emergency calling
- Number porting
- Outbound restrictions
- Configuration changes
- Monitoring
- Reporting
- Escalation

## 4. Activities

- Define support ownership.
- Define L1/L2/L3 responsibilities.
- Define carrier escalation.
- Define Genesys escalation.
- Define number management.
- Define change process.
- Define incident process.
- Define voice-quality troubleshooting.
- Define emergency process.
- Define monitoring.
- Create runbooks.
- Train support teams.

## 5. Deliverables

- Voice operations runbook
- Carrier support matrix
- Troubleshooting guide
- Number-management procedure
- Escalation matrix
- Emergency procedure
- Change-management procedure

## 6. Acceptance Criteria

Operations can independently manage and troubleshoot the deployed voice service.

## 7. Definition of Done

Voice operations documentation, ownership, training and support processes are accepted.
