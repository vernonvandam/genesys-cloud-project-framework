# Layer 2.03.17 — Caller ID & ANI

## 1. Purpose

Define the telephone number presented to customers during outbound calling.

## 2. Classification

**Required**

## 3. Discovery

Determine:

- Queue caller ID
- Agent caller ID
- Geographic number
- Main business number
- Privacy requirements
- Carrier restrictions
- Callback requirements

## 4. Activities

- Define caller ID strategy.
- Map numbers to queues/business units where applicable.
- Configure outbound caller ID.
- Test presentation.
- Test callback.
- Validate carrier behaviour.

## 5. Risks

- Incorrect number presented.
- Unusable callback number.
- Carrier overwrites caller ID.

## 6. Acceptance Criteria

Outbound calls present the approved caller ID.

## 7. Definition of Done

Caller ID behaviour is configured, tested and documented.
