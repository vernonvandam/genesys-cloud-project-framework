# Layer 2.03.06 — Genesys Cloud Voice

## 1. Purpose

Evaluate and implement Genesys Cloud Voice where it is the approved PSTN model.

## 2. Classification

**Conditional**

Availability and suitability must be validated for the customer's country/region and requirements.

## 3. Discovery

Determine:

- Geographic availability
- Number requirements
- Porting requirements
- Emergency calling
- Regulatory obligations
- Caller ID
- Outbound calling
- Resilience
- Customer carrier requirements

## 4. Activities

- Confirm eligibility.
- Confirm number availability.
- Confirm porting options.
- Configure telephony.
- Assign numbers.
- Configure routing.
- Test inbound.
- Test outbound.
- Test caller ID.
- Test emergency services where required.

## 5. Acceptance Criteria

Genesys Cloud Voice meets all approved telephony requirements.

## 6. Definition of Done

Genesys Cloud Voice is operational, tested and accepted.
