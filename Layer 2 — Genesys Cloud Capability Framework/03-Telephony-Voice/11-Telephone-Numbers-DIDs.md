# Layer 2.03.11 — Telephone Numbers & DIDs

## 1. Purpose

Establish complete ownership, allocation and configuration of telephone numbers.

## 2. Classification

**Required**

## 3. Discovery

Capture:

- Number
- Country
- Region
- Type
- Current owner
- Carrier
- Current destination
- Target destination
- Business purpose
- Queue/IVR mapping
- Porting status

## 4. Activities

1. Build number inventory.
2. Validate ownership.
3. Categorise numbers.
4. Identify obsolete numbers.
5. Map target destinations.
6. Configure required numbers.
7. Validate inbound routing.
8. Validate outbound usage.
9. Document final state.

## 5. Deliverables

- Number inventory
- Number mapping
- Number assignment matrix

## 6. Acceptance Criteria

Every production number has an approved destination and ownership status.

## 7. Definition of Done

Number inventory and configuration are complete and validated.
