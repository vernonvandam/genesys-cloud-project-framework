# Layer 2.03.24 — Carrier Redundancy & Resilience

## 1. Purpose

Design carrier resilience for business-critical voice services.

## 2. Classification

**Conditional**

## 3. Discovery

Determine:

- Single vs multiple carrier
- Geographic diversity
- Carrier SLA
- Failover mechanism
- Number portability
- Disaster recovery
- Cost implications

## 4. Activities

- Assess carrier resilience.
- Define target model.
- Define failure scenarios.
- Configure redundancy where supported.
- Test primary failure.
- Test secondary recovery.
- Document carrier escalation.

## 5. Acceptance Criteria

Carrier resilience meets approved availability requirements.

## 6. Definition of Done

Carrier resilience is implemented and tested where required.
