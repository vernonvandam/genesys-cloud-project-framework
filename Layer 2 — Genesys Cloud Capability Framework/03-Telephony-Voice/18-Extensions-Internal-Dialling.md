# Layer 2.03.18 — Extensions & Internal Dialling

## 1. Purpose

Define internal extension numbering and internal telephony behaviour.

## 2. Classification

**Conditional**

## 3. Discovery

Determine:

- Existing extension plan
- Required extension length
- Site-specific prefixes
- User extensions
- Queue extensions
- Internal transfer requirements
- Legacy PBX dependencies

## 4. Activities

- Define extension scheme.
- Map users.
- Configure required extensions.
- Test internal calling.
- Test transfer.
- Test conference.
- Test cross-site calling.

## 5. Acceptance Criteria

Internal dialling works according to the approved numbering plan.

## 6. Definition of Done

Extension architecture is implemented and validated.
