# Layer 2.03.04 — BYOC Cloud

## 1. Purpose

Define and implement BYOC Cloud where the customer retains carrier/PSTN services while using Genesys Cloud cloud-based telephony connectivity.

## 2. Classification

**Conditional**

## 3. Discovery

Determine:

- Carrier
- SIP requirements
- Number ownership
- Number ranges
- Geographic requirements
- Codec requirements
- Carrier redundancy
- Caller ID
- Emergency calling
- Regulatory obligations

## 4. Activities

1. Confirm BYOC Cloud suitability.
2. Confirm carrier compatibility.
3. Design SIP architecture.
4. Define trunk configuration.
5. Define number mapping.
6. Configure trunk.
7. Configure number assignment.
8. Test inbound.
9. Test outbound.
10. Test caller ID.
11. Test failure conditions.

## 5. Dependencies

- Telephony model
- Carrier
- SIP
- Numbers
- Network
- Security

## 6. Acceptance Criteria

BYOC Cloud connectivity successfully supports all approved voice scenarios.

## 7. Definition of Done

BYOC Cloud is configured, tested and documented.
