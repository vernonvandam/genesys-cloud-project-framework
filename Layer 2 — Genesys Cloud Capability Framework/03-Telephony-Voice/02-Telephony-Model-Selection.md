# Layer 2.03.02 — Telephony Model Selection

## 1. Purpose

Determine the appropriate Genesys Cloud telephony model for the customer.

## 2. Classification

**Required**

## 3. Candidate Models

- Genesys Cloud Voice
- BYOC Cloud
- BYOC Premises
- Hybrid architectures where supported and justified

## 4. Decision Factors

Evaluate:

- Geography
- Carrier availability
- Existing carrier agreements
- Number ownership
- Existing SIP infrastructure
- Existing PBX dependencies
- Regulatory requirements
- Network architecture
- Resilience
- Cost
- Operational capability
- Migration strategy
- Local survivability
- Endpoint requirements

## 5. Activities

1. Capture requirements.
2. Assess Genesys Cloud Voice.
3. Assess BYOC Cloud.
4. Assess BYOC Premises.
5. Assess existing telephony dependencies.
6. Compare models.
7. Document recommendation.
8. Review with customer.
9. Obtain architecture decision.

## 6. Deliverables

- Telephony model decision matrix
- Architecture decision record
- Target telephony model

## 7. Acceptance Criteria

Customer approves the selected telephony model.

## 8. Definition of Done

Telephony model is formally selected and all rejected alternatives have documented rationale where appropriate.
