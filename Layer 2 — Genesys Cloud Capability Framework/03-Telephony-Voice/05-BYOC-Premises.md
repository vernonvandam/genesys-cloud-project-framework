# Layer 2.03.05 — BYOC Premises

## 1. Purpose

Design and implement BYOC Premises where on-premises telephony infrastructure and Genesys Cloud Edges are required.

## 2. Classification

**Conditional**

## 3. Discovery

Determine:

- Existing PBX
- SIP infrastructure
- Carrier
- Edge requirements
- Sites
- Network topology
- Local survivability
- PSTN routing
- Hardware lifecycle
- Support model

## 4. Activities

- Assess existing telephony infrastructure.
- Confirm BYOC Premises requirement.
- Design Edge architecture.
- Design SIP trunks.
- Design carrier connectivity.
- Define network requirements.
- Deploy/configure required infrastructure.
- Validate registration/connectivity.
- Validate inbound.
- Validate outbound.
- Validate failure scenarios.

## 5. Risks

- Legacy PBX dependency.
- Hardware failure.
- Network failure.
- Incorrect SIP configuration.
- Insufficient operational support.

## 6. Acceptance Criteria

Required BYOC Premises infrastructure is operational and supports approved call scenarios.

## 7. Definition of Done

BYOC Premises architecture, configuration, testing and support model are complete.
