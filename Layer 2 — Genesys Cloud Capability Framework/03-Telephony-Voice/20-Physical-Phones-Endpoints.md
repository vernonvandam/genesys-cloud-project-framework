# Layer 2.03.20 — Physical Phones & Endpoints

## 1. Purpose

Design and deploy physical telephony endpoints where required.

## 2. Classification

**Conditional**

## 3. Discovery

Determine:

- Physical phone requirement
- Models
- Locations
- User types
- Provisioning
- Firmware
- Network
- PoE
- Headsets
- Reception phones
- Common-area phones

## 4. Activities

- Select supported devices.
- Validate firmware.
- Prepare network.
- Provision phones.
- Assign users.
- Validate registration.
- Test inbound.
- Test outbound.
- Test transfer.
- Test hold.
- Test conference.

## 5. Acceptance Criteria

Required physical phones operate correctly in their intended use cases.

## 6. Definition of Done

Physical endpoints are deployed, tested and documented.
