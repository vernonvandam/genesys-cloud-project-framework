# Layer 2.03.14 — Number Plans & Call Classification

## 1. Purpose

Define how telephone numbers and destinations are classified and handled by the telephony platform.

## 2. Classification

**Required**

## 3. Scope

- Local
- National
- International
- Emergency
- Premium/special
- Internal
- Restricted
- Blocked
- Customer-specific classifications

## 4. Activities

- Define classification requirements.
- Map number ranges.
- Define routing behaviour.
- Define restrictions.
- Configure classifications.
- Test allowed calls.
- Test blocked calls.
- Test restricted calls.

## 5. Acceptance Criteria

Number classifications produce the approved routing and security behaviour.

## 6. Definition of Done

Number plans and classifications are configured and validated.
