# Layer 2.03.15 — Inbound Call Routing

## 1. Purpose

Define how inbound PSTN calls enter Genesys Cloud and reach the correct business destination.

## 2. Classification

**Required**

## 3. Scope

- DIDs
- Number mappings
- IVRs
- Queues
- Business units
- Schedules
- Holidays
- Overflow
- Failover
- After-hours
- Emergency/business exceptions

## 4. Activities

1. Map every inbound number.
2. Define destination.
3. Define business hours.
4. Define after-hours.
5. Define holiday handling.
6. Define overflow.
7. Define failure behaviour.
8. Configure routing.
9. Test each number.
10. Test after-hours.
11. Test holidays.
12. Test overflow.
13. Test failure conditions.

## 5. Deliverables

- Inbound number map
- Routing design
- Test matrix

## 6. Acceptance Criteria

Every production inbound number reaches the approved destination under all relevant conditions.

## 7. Definition of Done

Inbound routing is configured and fully tested.
