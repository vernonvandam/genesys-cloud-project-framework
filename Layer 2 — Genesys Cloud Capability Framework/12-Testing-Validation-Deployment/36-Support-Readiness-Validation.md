# 36 — Support Readiness Validation

## Capability Definition

Validates that support teams can diagnose, resolve and escalate common Genesys Cloud incidents following production deployment.

---

# 1. Scope

- L1 support
- L2 support
- L3 support
- Service desk
- Escalation
- Knowledge
- Troubleshooting
- Vendor escalation

---

# 2. Classification

**Required**

---

# 3. Discovery Activities

- Identify support tiers.
- Identify common incidents.
- Identify escalation paths.
- Identify knowledge requirements.

---

# 4. Design Activities

- Define support scenarios.
- Define troubleshooting exercises.
- Define escalation tests.
- Define knowledge validation.

---

# 5. Implementation Activities

```text
Brief support teams
Provide knowledge articles
Provide runbooks
Execute incident simulations
Test troubleshooting
Test escalation
Test vendor escalation
Validate support tools
Record gaps
Remediate gaps
Confirm support readiness
```

# 6. Dependencies

- Operations
- Knowledge Management
- Runbooks
- Incident Management

- Troubleshooting validated.
- Escalation validated.
- Knowledge available.

---

# 14. Definition of Done

Support organisation is ready to support production.
