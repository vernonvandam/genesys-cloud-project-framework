# 24 — Compliance Testing

## Capability Definition

Validates compliance controls, policies, retention, recording, access and audit requirements against approved regulatory and organisational obligations.

---

# 1. Scope

- Privacy
- Recording
- Retention
- Access
- Audit
- Data residency
- Regulatory controls
- Compliance policies

---

# 2. Classification

**Required**

---

# 3. Discovery Activities

- Identify applicable regulations.
- Identify organisational policies.
- Identify data classifications.
- Identify retention requirements.
- Identify recording requirements.

---

# 4. Design Activities

- Map requirements to controls.
- Define compliance test cases.
- Define evidence requirements.
- Define exception scenarios.

# 5. Implementation Activities

```text
Map compliance requirements
Validate privacy controls
Validate recording controls
Validate retention
Validate access
Validate audit evidence
Validate data handling
Validate compliance reporting
Test exception scenarios

Remediate gaps
Obtain compliance approval
```
