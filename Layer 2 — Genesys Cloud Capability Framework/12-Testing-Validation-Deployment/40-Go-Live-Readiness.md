# 40 — Go-Live Readiness

## Capability Definition

Provides the formal assessment and approval that the Genesys Cloud solution, organisation, users, integrations, support model and business are ready for production.

---

# 1. Scope

- Technical readiness
- Functional readiness
- UAT
- Security
- Compliance
- Operations
- Training
- Migration
- Cutover
- Support
- Business readiness

---

# 2. Classification

**Required**

---

# 3. Discovery Activities

Review:

- Test results
- UAT
- Defects
- Operational readiness
- Training
- Migration
- Cutover
- Security
- Compliance

---

# 4. Design Activities

- Define readiness checklist.
- Define mandatory criteria.
- Define go/no-go thresholds.
- Define approval authority.
- Define outstanding issue treatment.

---

# 5. Implementation Activities

```text
Review functional testing
Review integration testing
Review UAT
Review defects
Review security
Review compliance
Review training
Review support readiness
Review migration
Review cutover
Review rollback
Review communications
Complete Go-Live Readiness Assessment
Obtain approvals
Conduct go/no-go meeting
```

---

# 6. Dependencies

All major Layer 2 domains.

---

# 7. Layer 1 Mapping

Primary:

- Phase 9 — Operational Readiness & Cutover Preparation
- Phase 10 — Production Deployment & Go-Live

---

# 8. Roles

- Project Manager
- Solution Architect
- Test Manager
- Service Manager
- Business Owner
- Customer Product Owner

---

# 9. Customer Responsibilities

- Review readiness.
- Accept residual risk.
- Approve go-live.
- Provide final business approval.

---

# 10. Testing

Confirm all mandatory test exit criteria have been met.

---

# 11. Deliverables

- Go-Live Readiness Checklist
- Readiness Assessment
- Risk Register
- Go/No-Go Decision

---

# 12. Effort Drivers

- Solution complexity
- Number of stakeholders
- Defect volume
- Regulatory requirements
- Migration complexity

---

# 13. Acceptance Criteria

- Mandatory readiness criteria met.
- No unacceptable critical defects.
- Operational readiness achieved.
- Rollback ready.
- Business approval obtained.

---

# 14. Definition of Done

Formal go-live approval is obtained.
