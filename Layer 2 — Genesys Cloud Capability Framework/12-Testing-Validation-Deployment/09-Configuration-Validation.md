# 09 — Configuration Validation

## Capability Definition

Validates that Genesys Cloud configuration matches approved solution design and requirements before formal functional testing.

---

# 1. Scope

- Organisation configuration
- Divisions
- Users
- Roles
- Queues
- Skills
- Routing
- Architect
- Telephony
- Digital
- Integrations
- Data
- Policies

---

# 2. Classification

**Required**

---

# 3. Discovery Activities

- Identify configuration sources.
- Identify approved design documents.
- Identify configuration baselines.
- Identify critical configuration.

---

# 4. Design Activities

- Define configuration checklist.
- Define validation evidence.
- Define configuration comparison approach.
- Define baseline approval.

---

# 5. Implementation Activities

```text
Review approved design
Extract current configuration
Compare configuration to design
Validate organisation settings
Validate divisions
Validate users and roles
Validate queues and skills
Validate routing
Validate Architect
Validate telephony
Validate digital
Validate integrations
Validate data configuration
Record discrepancies
Remediate configuration
Repeat validation
Approve configuration baseline
```

---

# 6. Dependencies

- Solution Design
- Platform Configuration
- Test Environment
- Requirements

---

# 7. Layer 1 Mapping

Primary:

- Phase 6 — Configuration & Build
- Phase 8 — Testing & Validation

---

# 8. Roles

- Genesys Cloud Architect
- Genesys Cloud Engineer
- Test Lead
- Solution Architect

---

# 9. Customer Responsibilities

- Validate business configuration.
- Approve discrepancies.
- Confirm baseline.

---

# 10. Testing

Configuration validation is itself a precondition to functional testing.

---

# 11. Deliverables

- Configuration Validation Checklist
- Configuration Baseline
- Discrepancy Register
- Validation Evidence

---

# 12. Effort Drivers

- Number of objects
- Configuration complexity
- Number of capabilities
- Number of environments
- Manual versus automated validation

---

# 13. Acceptance Criteria

- Configuration matches approved design.
- Exceptions documented.
- Critical discrepancies resolved.
- Baseline approved.

---

# 14. Definition of Done

The environment configuration is validated and approved for functional testing.
