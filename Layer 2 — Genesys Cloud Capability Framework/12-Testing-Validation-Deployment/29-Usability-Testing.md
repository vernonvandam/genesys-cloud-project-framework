# 29 — Usability Testing

## Capability Definition

Validates whether customer, agent, supervisor and administrator experiences are understandable, efficient and suitable for intended users.

---

# 1. Scope

- Agent experience
- Supervisor experience
- Customer experience
- Administrative workflows
- Navigation
- Usability
- Training impacts

---

# 2. Classification

**Required**

---

# 3. Discovery Activities

- Identify user personas.
- Identify critical workflows.
- Identify usability objectives.
- Identify existing pain points.

---

# 4. Design Activities

- Define usability scenarios.
- Define observation criteria.
- Define feedback collection.
- Define usability acceptance criteria.

---

# 5. Implementation Activities

```text
Select representative users
Brief participants
Execute representative workflows
Observe task completion
Measure usability issues
Collect user feedback
Record issues
Prioritise findings
Remediate issues
Retest
```

---

# 6. Dependencies

- UAT
- Agent Experience
- Digital
- WFM
- Training

---

# 7. Layer 1 Mapping

Primary:

- Phase 8 — Testing & Validation
- Phase 9 — Operational Readiness & Cutover Preparation

---

# 8. Roles

- UX Specialist
- Test Lead
- Business SMEs
- Agents
- Supervisors

---

# 9. Customer Responsibilities

- Provide representative users.
- Provide feedback.
- Approve usability.

---

# 10. Testing

Observe real users performing representative tasks.

---

# 11. Deliverables

- Usability Test Plan
- Usability Findings
- Remediation Register

---

# 12. Effort Drivers

- Number of personas
- Number of workflows
- Number of users
- Complexity of solution

---

# 13. Acceptance Criteria

- Representative users participate.
- Critical usability issues resolved.
- Business accepts user experience.

---

# 14. Definition of Done

Usability is validated for critical user journeys.
