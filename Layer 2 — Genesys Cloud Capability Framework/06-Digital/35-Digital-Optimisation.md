# Layer 2.06.35 — Digital Optimisation

## Purpose

Continuously improve customer experience, channel efficiency and operational performance.

## Classification

**Required**

## Optimisation Areas

- Customer effort
- Self-service
- Bot containment
- Response time
- Abandonment
- First-contact resolution
- Transfer rate
- Agent productivity
- Email backlog
- Channel adoption
- Customer satisfaction

## Activities

- Establish baseline.
- Review KPIs.
- Analyse customer journeys.
- Identify failure points.
- Review bot performance.
- Review routing.
- Review queue performance.
- Review agent handling.
- Implement improvements.
- Regression test.
- Measure results.

## Acceptance Criteria

Optimisation initiatives have measurable outcomes.

## Definition of Done

Digital optimisation is included in the BAU operating model.
