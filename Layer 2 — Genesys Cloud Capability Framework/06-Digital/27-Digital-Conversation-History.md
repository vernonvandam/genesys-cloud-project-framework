# Layer 2.06.27 — Digital Conversation History

## Purpose

Maintain appropriate visibility of previous customer digital interactions.

## Classification

**Required**

## Activities

- Define history requirements.
- Define retention.
- Define identity mapping.
- Define agent visibility.
- Define privacy restrictions.
- Validate history.
- Test authenticated customer.
- Test anonymous customer.
- Test transferred conversation.

## Acceptance Criteria

Approved conversation history is available to authorised users.

## Definition of Done

Conversation-history behaviour is validated.
