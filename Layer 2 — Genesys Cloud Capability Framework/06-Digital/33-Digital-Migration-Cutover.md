# Layer 2.06.33 — Digital Migration & Cutover

## Purpose

Migrate existing digital channels to the target Genesys Cloud solution.

## Classification

**Conditional**

## Activities

### Discovery

- Inventory current channels.
- Identify current providers.
- Identify current numbers/accounts.
- Identify integrations.
- Identify content.
- Identify routing.
- Identify customer journeys.

### Design

- Map current state.
- Design target state.
- Define migration waves.
- Define dependencies.

### Build

- Configure target channels.
- Configure routing.
- Configure integrations.
- Configure agent handling.
- Test.

### Cutover

- Freeze changes.
- Validate production.
- Activate channel.
- Execute smoke tests.
- Monitor.

### Rollback

- Define rollback triggers.
- Define rollback mechanism.
- Validate legacy readiness.

## Acceptance Criteria

Digital customer journeys operate correctly after cutover.

## Definition of Done

Migration is complete and accepted.
