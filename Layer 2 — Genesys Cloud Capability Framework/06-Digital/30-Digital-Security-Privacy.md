# Layer 2.06.30 — Digital Security & Privacy

## Purpose

Protect digital customer data and interactions.

## Classification

**Required**

## Scope

- Authentication
- Authorisation
- PII
- Sensitive data
- Attachments
- Customer identity
- Session management
- Access controls
- Data retention
- Privacy

## Activities

- Conduct security assessment.
- Conduct privacy assessment.
- Identify sensitive data.
- Define access controls.
- Define retention.
- Define attachment controls.
- Review integrations.
- Execute security testing.
- Remediate findings.

## Acceptance Criteria

Digital solution meets customer and organisational security requirements.

## Definition of Done

Security and privacy approval is obtained.
