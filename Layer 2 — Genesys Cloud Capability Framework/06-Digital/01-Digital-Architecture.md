# Layer 2.06.01 — Digital Architecture

## Purpose

Define the target-state architecture for all Genesys Cloud digital channels.

## Classification

**Required**

## Activities

1. Inventory required channels.
2. Identify customer journeys.
3. Identify channel entry points.
4. Define channel ownership.
5. Define identity architecture.
6. Define routing architecture.
7. Define bot integration.
8. Define Architect integration.
9. Define agent handling.
10. Define reporting.
11. Define security.
12. Define operational support.
13. Obtain architecture approval.

## Deliverables

- Digital architecture
- Channel architecture
- Integration architecture
- Digital customer journey architecture

## Acceptance Criteria

All approved digital channels and journeys are represented in the target architecture.

## Definition of Done

Architecture is approved by business, technical and operational stakeholders.
