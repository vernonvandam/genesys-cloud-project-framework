# Layer 2.15.18 — Data Optimisation

## Capability Definition

Improves the quality, structure, availability, ownership and usability of Genesys Cloud data used by operational and analytical processes.

---

# 1. Scope

- Data quality
- Data models
- Data ownership
- Data retention
- Data transformation
- Data availability
- Data governance

---

# 2. Classification

**Required**

- Inventory key data.

- Identify data gaps.
- Review ownership.

- Identify redundant data.

- Define data improvement objectives.
- Define quality controls.
- Improve data models.
- Define ownership.
- Improve data availability.
- Define retention requirements.
