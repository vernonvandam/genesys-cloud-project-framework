# Layer 2.15.02 — Optimisation Governance

## Capability Definition

Provides governance for identifying, assessing, approving, prioritising, implementing and measuring Genesys Cloud optimisation initiatives.

---

# 1. Scope

- Optimisation governance
- Decision rights
- Improvement approvals
- Prioritisation
- Risk management
- Change governance
- Benefits tracking
- Governance cadence

---

# 2. Classification

**Required**

---

# 3. Discovery Activities

- Identify governance stakeholders.
- Review existing governance forums.
- Identify decision authorities.
- Identify optimisation risks.
- Review existing change processes.

---

# 4. Design Activities

- Define governance structure.
- Define decision rights.
- Define optimisation approval process.
- Define prioritisation criteria.
- Define reporting requirements.
- Define governance cadence.
