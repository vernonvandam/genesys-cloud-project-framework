   ↓

   ↓

   ↓

# 13. Optimisation Principles

The optimisation process shall:

1. Start with measurable evidence.
2. Establish a baseline.
3. Identify the business problem.
4. Quantify expected value.
5. Assess technical feasibility.
6. Assess security and compliance.
7. Assess operational impact.
8. Prioritise against competing work.
9. Test changes before deployment.
10. Measure post-deployment outcomes.
11. Validate benefits.
12. Update the roadmap and backlog.
