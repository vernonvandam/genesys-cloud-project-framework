# Layer 2.15.29 — Licensing Optimisation

## Capability Definition

Optimises Genesys Cloud licensing to align feature entitlement and user licensing with actual usage, business requirements and cost objectives.

---

# 1. Scope

- Licensing
- Entitlements
- User assignments
- Feature adoption
- Utilisation
- Cost management
- Licence governance

---

# 2. Classification

**Required**

---

# 3. Discovery Activities

- Inventory licences.
- Review assignments.
- Analyse utilisation.
- Identify unused licences.
- Review feature entitlement.
- Identify licence gaps.

---

# 4. Design Activities

- Define licensing strategy.
- Optimise licence allocation.
- Define licence governance.
- Define review cadence.
- Align licences to roles.
