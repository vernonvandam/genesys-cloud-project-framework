# Layer 2.02.18 — Privileged Administration

## 1. Purpose

Control access to high-risk Genesys Cloud administrative capabilities.

## 2. Classification

**Required**

## 3. Discovery

Identify:

- Super administrators.
- Platform administrators.
- Security administrators.
- IAM administrators.
- Architect administrators.
- Integration administrators.
- WFM administrators.
- Reporting administrators.
- Support administrators.

## 4. Design

Apply:

- Least privilege.
- Separation of duties.
- Administrative role separation.
- Restricted production access.
- Privileged review.
- Auditability.

## 5. Implementation

- Define privileged personas.
- Create roles.
- Assign permissions.
- Restrict divisions.
- Restrict environment access.
- Validate effective permissions.

## 6. Testing

Test:

- Required administrative functions.
- Prohibited functions.
- Cross-division access.
- Production access.
- Privileged changes.

## 7. Acceptance Criteria

Privileged users have only the permissions necessary for their responsibilities.

## 8. Definition of Done

Privileged access is implemented, tested, documented and governed.
