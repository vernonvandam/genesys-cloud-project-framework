# Layer 2.02.05 — Authentication & MFA

## 1. Purpose

Define authentication controls and multi-factor authentication requirements.

## 2. Classification

**Required**

MFA implementation is conditional on the customer's authentication architecture and security requirements.

## 3. Discovery

Determine:

- Authentication mechanism.
- MFA provider.
- MFA enforcement.
- Conditional access.
- Administrator MFA.
- Agent MFA.
- Remote access requirements.
- Exceptions.
- Recovery process.

## 4. Implementation

- Define authentication policy.
- Configure required controls.
- Configure MFA where applicable.
- Test standard authentication.
- Test MFA.
- Test failed MFA.
- Test account recovery.
- Test administrator authentication.
- Document support procedures.

## 5. Security

Apply:

- Least privilege
- Strong authentication
- MFA
- Restricted exceptions
- Monitoring
- Emergency access

## 6. Testing

Test:

- Valid credentials.
- Invalid credentials.
- MFA success.
- MFA failure.
- Unauthorised user.
- Administrator.
- Disabled user.
- Expired/revoked identity.

## 7. Acceptance Criteria

Authentication meets the approved security policy.

## 8. Definition of Done

Authentication and MFA controls are configured, tested and accepted.
