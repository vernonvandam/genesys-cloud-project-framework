# Layer 2.02.11 — External / Guest Access

## 1. Purpose

Control access by external parties such as contractors, partners or other approved users.

## 2. Classification

**Conditional**

## 3. Discovery

Determine:

- External user categories.
- Required access.
- Duration.
- Sponsorship.
- Authentication.
- MFA.
- Division restrictions.
- Administrative restrictions.
- Offboarding.

## 4. Design

- Define approval process.
- Define access boundaries.
- Define expiry/review.
- Define owner.
- Define audit requirements.

## 5. Implementation

- Create approved external identities.
- Assign minimum access.
- Validate restrictions.
- Document ownership.
- Test termination.

## 6. Risks

- Unmanaged external accounts.
- Stale access.
- Excessive permissions.

## 7. Acceptance Criteria

External users have documented ownership, approved access and controlled lifecycle.

## 8. Definition of Done

External access is configured and governed according to customer security policy.
