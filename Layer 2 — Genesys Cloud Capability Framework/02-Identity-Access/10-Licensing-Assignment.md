# Layer 2.02.10 — Licensing Assignment

## 1. Purpose

Define how Genesys Cloud licences are assigned to user types.

## 2. Classification

**Required**

## 3. Discovery

Identify:

- Agents.
- Supervisors.
- Administrators.
- WFM users.
- QM users.
- Reporting users.
- Digital users.
- AI users.
- Temporary/contractor users.

## 4. Design

Create:

- User persona matrix.
- Licence matrix.
- Assignment rules.
- Exception process.
- Review process.

## 5. Implementation

- Configure licence assignment.
- Assign licences.
- Validate features.
- Test users.
- Test lifecycle changes.

## 6. Risks

- Over-licensing.
- Under-licensing.
- Incorrect user entitlements.
- Licence drift.

## 7. Acceptance Criteria

All users have the minimum licence entitlement required for their approved functions.

## 8. Definition of Done

Licence assignments are implemented and validated.
