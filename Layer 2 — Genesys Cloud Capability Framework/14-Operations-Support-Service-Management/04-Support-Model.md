# Layer 2.14.04 — Support Model

## Capability Definition

The Support Model defines how Genesys Cloud incidents, requests, problems and technical issues are supported across customer, partner and vendor teams.

---

# 1. Scope

- Support tiers
- Support hours
- Support responsibilities
- Escalation paths
- Incident ownership
- Vendor escalation
- Service desk integration
- Priority model
- SLA expectations

---

# 2. Classification

**Required**

---

# 3. Discovery Activities

- Identify existing support model.
- Identify support teams.
- Identify service hours.
- Identify ITSM processes.
- Identify SLA requirements.
- Identify vendor support arrangements.
- Identify escalation requirements.

---

# 4. Design Activities

- Define L1/L2/L3 responsibilities.
- Define support boundaries.
- Define escalation procedures.
- Define support hours.
- Define incident priorities.
- Define SLA/OLA expectations.
- Define Genesys vendor escalation.
