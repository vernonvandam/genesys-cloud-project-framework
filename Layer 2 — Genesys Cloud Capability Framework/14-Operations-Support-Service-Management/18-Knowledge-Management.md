# Layer 2.14.18 — Knowledge Management

## Capability Definition

Knowledge Management provides controlled operational knowledge for support teams, administrators and users.

---

# 1. Scope

- Knowledge articles
- Troubleshooting
- FAQs
- Support procedures
- Technical documentation
- Known errors
- User guidance
- Knowledge lifecycle

---

# 2. Classification

**Required**

---

# 3. Discovery Activities

- Identify existing knowledge sources.
- Identify knowledge gaps.
- Identify target audiences.
- Identify content owners.
- Identify review requirements.

---

# 4. Design Activities

- Define knowledge structure.
- Define article standards.
- Define approval process.
- Define review lifecycle.
- Define knowledge ownership.
- Define publication model.
