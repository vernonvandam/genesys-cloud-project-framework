# Layer 2.14.01 — Operating Model

## Capability Definition

The Operating Model defines how Genesys Cloud is governed, administered, supported, monitored and continuously improved after implementation.

---

# 1. Scope

- Genesys Cloud operating model
- Operational ownership
- Administration responsibilities
- Support responsibilities
- Governance forums
- Operational processes
- Escalation paths
- Service management integration
- BAU responsibilities
- Continuous improvement responsibilities

---

# 2. Classification

**Required**

---

# 3. Discovery Activities

- Identify existing operating model.
- Identify customer operational teams.
- Identify Genesys Cloud administrators.
- Identify service desk and support teams.
- Identify existing ITSM processes.
- Identify escalation paths.
- Identify operational governance forums.
- Identify operational reporting requirements.
- Identify customer ownership boundaries.

# 4. Design Activities

- Define Genesys Cloud operating model.
- Define operational ownership.
- Define administration responsibilities.

- Define governance structure.
- Define operational processes.
- Define BAU responsibilities.
- Define continuous improvement model.
- Define service-management integration.
