# Layer 2.14.09 — Genesys Vendor Escalation

## Capability Definition

Genesys Vendor Escalation defines the process for engaging Genesys Support for platform defects, service issues and complex technical incidents.

---

# 1. Scope

- Genesys Support
- Case creation
- Case severity
- Evidence collection
- Escalation
- Case management
- Vendor communications
- Resolution validation

---

# 2. Classification

**Required**

---

# 3. Discovery Activities

- Identify support severity model.
- Identify vendor escalation requirements.
- Identify evidence requirements.

---

# 4. Design Activities

- Define case ownership.
- Define evidence standards.
