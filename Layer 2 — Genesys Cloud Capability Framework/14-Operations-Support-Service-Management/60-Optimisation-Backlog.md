# Layer 2.14.60 — Optimisation Backlog

## Capability Definition

The Optimisation Backlog provides the controlled repository for future Genesys Cloud enhancements, optimisation opportunities, technical debt and platform evolution.

---

# 1. Scope

- Enhancement requests
- Technical debt
- Automation
- Performance improvements
- Cost optimisation
- User experience
- New Genesys capabilities
- Platform evolution

---

# 2. Classification

**Required**

---

# 3. Discovery Activities

- Identify known optimisation opportunities.
- Review technical debt.
- Review user feedback.
- Review performance.
- Identify new platform capabilities.
- Identify automation opportunities.

---

# 4. Design Activities

- Define prioritisation.
- Define scoring.
- Define ownership.
- Define governance.
- Define benefits tracking.
