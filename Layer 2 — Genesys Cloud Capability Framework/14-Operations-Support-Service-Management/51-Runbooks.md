# Layer 2.14.51 — Runbooks

## Capability Definition

Runbooks provide repeatable operational instructions for common Genesys Cloud administration, troubleshooting, recovery and support activities.

---

# 1. Scope

- Administration runbooks
- Incident runbooks
- Troubleshooting
- Recovery
- Monitoring
- Telephony
- Integrations
- Routing
- Architect
- Digital

---

# 2. Classification

**Required**

---

# 3. Discovery Activities

- Identify recurring operational activities.
- Identify common incidents.
- Identify recovery scenarios.
- Identify SMEs.
- Identify runbook gaps.

---

# 4. Design Activities

- Define runbook template.
- Define execution standards.
- Define approvals.
- Define validation.
- Define ownership.
- Define review cadence.
