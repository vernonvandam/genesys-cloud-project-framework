# Layer 2.04.22 — Callback Routing

## 1. Purpose

Define how customers requesting a callback are represented, queued and delivered to agents.

## 2. Classification

**Conditional**

## 3. Discovery

Determine:

- Callback eligibility
- Queue association
- Number capture
- Scheduling
- Retry behaviour
- Priority
- Agent selection
- Failure handling

## 4. Activities

- Define callback requirements.
- Define queue mapping.
- Define retry rules.
- Configure callback.
- Test callback request.
- Test callback delivery.
- Test failed callback.
- Test retry behaviour.

## 5. Acceptance Criteria

Callbacks are delivered according to approved business rules.

## 6. Definition of Done

Callback routing is configured, tested and documented.
