# Layer 2.04.21 — Holiday Routing

## 1. Purpose

Define routing behaviour during public holidays and customer-specific closure periods.

## 2. Classification

**Required**

## 3. Discovery

Determine:

- Public holidays
- Customer-specific holidays
- Regional holidays
- Time zones
- Emergency exceptions

## 4. Activities

- Build holiday calendar.
- Define holiday schedules.
- Map schedules to queues/flows.
- Configure routing.
- Test holiday behaviour.
- Validate year rollover process.

## 5. Acceptance Criteria

Holiday periods trigger the approved routing behaviour.

## 6. Definition of Done

Holiday routing is configured and operationally maintainable.
