# Layer 2.04.12 — Presence & Routing Status

## 1. Purpose

Ensure agent presence and routing status correctly determine interaction eligibility.

## 2. Classification

**Required**

## 3. Scope

- Presence
- Routing status
- Available
- Busy
- Away
- Offline
- Not Responding
- On Queue
- Off Queue
- System-driven status

## 4. Activities

- Define presence model.
- Define routing-status behaviour.
- Define agent state requirements.
- Configure appropriate settings.
- Test each state.
- Validate queue routing.

## 5. Acceptance Criteria

Interactions are offered only to agents in valid routing states.

## 6. Definition of Done

Presence and routing-state behaviour is tested and documented.
