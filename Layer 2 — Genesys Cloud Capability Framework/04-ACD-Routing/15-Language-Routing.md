# Layer 2.04.15 — Language Routing

## 1. Purpose

Route interactions to agents with the required language capability.

## 2. Classification

**Conditional**

## 3. Discovery

Determine:

- Supported languages
- Language identification
- Language skill model
- Agent proficiency
- Fallback language
- Translation options

## 4. Activities

- Define language taxonomy.
- Define agent language skills.
- Define interaction language identification.
- Configure routing.
- Test each language.
- Test unavailable-language scenarios.

## 5. Acceptance Criteria

Interactions route to appropriately qualified language agents.

## 6. Definition of Done

Language routing is configured and validated.
