# Layer 2.04.08 — Skill Proficiency

## 1. Purpose

Define proficiency levels and how they affect routing.

## 2. Classification

**Conditional**

## 3. Discovery

Determine:

- Proficiency scale
- Minimum proficiency
- Skill assignment process
- Agent proficiency ownership
- Routing implications

## 4. Activities

- Define proficiency model.
- Map proficiency requirements.
- Configure proficiency.
- Assign test users.
- Test routing at different proficiency levels.
- Validate expected agent selection.

## 5. Acceptance Criteria

Routing behaviour correctly reflects approved proficiency requirements.

## 6. Definition of Done

Proficiency model is documented, configured and tested.
