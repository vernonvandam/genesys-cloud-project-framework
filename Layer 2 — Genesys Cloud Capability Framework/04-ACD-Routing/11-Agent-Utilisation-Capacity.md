# Layer 2.04.11 — Agent Utilisation & Capacity

## 1. Purpose

Define how concurrent interaction capacity and agent utilisation affect routing.

## 2. Classification

**Required**

## 3. Scope

- Voice
- Digital
- Concurrent interactions
- Agent capacity
- Utilisation
- Interaction priority
- Workforce Management dependencies

## 4. Activities

- Identify agent interaction profiles.
- Define expected concurrency.
- Define channel capacity.
- Configure applicable utilisation.
- Test simultaneous interactions.
- Validate routing under load.

## 5. Acceptance Criteria

Agents receive interactions according to approved capacity rules.

## 6. Definition of Done

Utilisation/capacity behaviour is configured and validated.
