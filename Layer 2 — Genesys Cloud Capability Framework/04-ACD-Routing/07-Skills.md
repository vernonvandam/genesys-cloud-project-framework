# Layer 2.04.07 — Skills

## 1. Purpose

Define the skill taxonomy required for skills-based routing.

## 2. Classification

**Conditional**

## 3. Discovery

Determine:

- Required skills
- Skill categories
- Business ownership
- Agent applicability
- Interaction applicability
- Skill lifecycle
- Reporting requirements

## 4. Design Principles

Avoid creating skills where another routing mechanism is more appropriate.

## 5. Activities

- Inventory existing skills.
- Rationalise skills.
- Define naming convention.
- Define skill ownership.
- Configure skills.
- Map skills to users.
- Map skills to interactions.
- Test skills routing.

## 6. Acceptance Criteria

Required skills route interactions to appropriately qualified agents.

## 7. Definition of Done

Skill taxonomy is approved, configured and validated.
