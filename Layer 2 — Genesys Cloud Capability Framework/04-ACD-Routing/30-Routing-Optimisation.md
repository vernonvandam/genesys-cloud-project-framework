# Layer 2.04.30 — Routing Optimisation

## 1. Purpose

Optimise routing based on operational performance and business outcomes.

## 2. Classification

**Required**

## 3. Optimisation Areas

- Service level
- Abandonment
- Occupancy
- Agent utilisation
- Skill efficiency
- Queue wait
- Overflow
- Customer experience
- Routing complexity

## 4. Activities

- Establish baseline metrics.
- Review routing performance.
- Identify bottlenecks.
- Identify over-complex rules.
- Review skill usage.
- Review queue utilisation.
- Recommend improvements.
- Test changes.
- Measure outcome.

## 5. Acceptance Criteria

Routing performance meets approved operational objectives.

## 6. Definition of Done

Routing is operationally optimised and improvement recommendations are documented.
