# Layer 2.04.27 — Agent Groups & Routing Pools

## 1. Purpose

Define logical pools of agents used to support routing requirements.

## 2. Classification

**Conditional**

## 3. Discovery

Determine:

- Agent teams
- Skill groups
- Business units
- Sites
- Languages
- Specialist teams
- Overflow groups

## 4. Activities

- Define agent groups.
- Map users.
- Map queues.
- Define routing eligibility.
- Configure groups.
- Test group routing.

## 5. Acceptance Criteria

Agent pools accurately represent the intended routing population.

## 6. Definition of Done

Required agent groups are configured and validated.
