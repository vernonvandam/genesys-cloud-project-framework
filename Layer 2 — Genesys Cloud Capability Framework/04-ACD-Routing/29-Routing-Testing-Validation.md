# Layer 2.04.29 — Routing Testing & Validation

## 1. Purpose

Validate that interactions are routed according to business and technical requirements.

## 2. Classification

**Required**

## 3. Test Areas

- Correct queue
- Incorrect queue prevention
- Skill routing
- Priority
- Agent availability
- Agent utilisation
- Bullseye
- Preferred agent
- Overflow
- Business hours
- Holidays
- Callback
- Voice
- Digital
- Email
- Messaging
- Failure conditions

## 4. Activities

1. Build routing test matrix.
2. Create test users.
3. Configure test skills.
4. Execute positive tests.
5. Execute negative tests.
6. Execute boundary tests.
7. Execute failure tests.
8. Log defects.
9. Retest.
10. Obtain UAT approval.

## 5. Acceptance Criteria

All critical routing scenarios pass.

## 6. Definition of Done

Routing has passed SIT, UAT and operational acceptance.
