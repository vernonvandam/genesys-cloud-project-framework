# Layer 2.05.18 — Data Tables

## Purpose

Provide configuration-driven lookup data for Architect flows.

## Classification

**Conditional**

## Potential Uses

- Routing rules
- Customer classifications
- Branch information
- Regional settings
- Product mappings
- Business rules
- Configuration values

## Activities

- Identify Data Table requirements.
- Define schema.
- Define key.
- Define values.
- Define ownership.
- Configure Data Tables.
- Load initial data.
- Test lookups.
- Test missing records.

## Acceptance Criteria

Flows return correct results for valid and invalid lookup scenarios.

## Definition of Done

Required Data Tables are configured, populated and tested.
