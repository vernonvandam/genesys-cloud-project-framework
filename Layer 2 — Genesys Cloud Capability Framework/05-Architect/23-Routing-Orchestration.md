# Layer 2.05.23 — Routing Orchestration

## Purpose

Determine the correct interaction destination based on customer, business and interaction context.

## Classification

**Required**

## Routing Inputs

- Queue
- Skills
- Language
- Priority
- Customer type
- Business function
- Product
- Time
- Customer context
- Agent availability

## Activities

- Define routing decision matrix.
- Identify routing inputs.
- Define precedence.
- Define fallback.
- Configure routing.
- Test combinations.
- Validate with ACD Routing team.

## Acceptance Criteria

Interactions reach the intended destination under all supported scenarios.

## Definition of Done

Routing orchestration is documented and tested.
