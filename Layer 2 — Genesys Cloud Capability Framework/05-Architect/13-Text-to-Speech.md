# Layer 2.05.13 — Text-to-Speech

## Purpose

Use text-to-speech for dynamic or configurable customer prompts.

## Classification

**Required**

## Considerations

- Voice
- Language
- Pronunciation
- Numeric values
- Dates
- Times
- Names
- Accessibility
- Customer experience

## Activities

- Identify TTS requirements.
- Define voice standards.
- Define language requirements.
- Test dynamic values.
- Validate pronunciation.
- Validate customer experience.

## Acceptance Criteria

TTS prompts are intelligible and appropriate.

## Definition of Done

TTS implementation is approved.
