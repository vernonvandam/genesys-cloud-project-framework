# Layer 2.05.12 — Prompt Management

## Purpose

Define and manage all prompts used by Architect.

## Classification

**Required**

## Scope

- Welcome
- Menu
- Error
- Authentication
- Queue
- Self-service
- Transfer
- Closure
- Callback
- Regulatory messaging

## Activities

- Build prompt catalogue.
- Define prompt ownership.
- Define script.
- Approve wording.
- Record audio where required.
- Configure prompts.
- Test playback.
- Validate version.

## Acceptance Criteria

All production prompts are approved and correctly referenced.

## Definition of Done

Prompt catalogue and associated flow references are complete.
