# Layer 2.05.21 — Customer Context & Lookup

## Purpose

Use customer information to personalise routing and self-service.

## Classification

**Conditional**

## Examples

- Customer identity
- Account status
- Customer tier
- Open case
- Service status
- Product ownership
- Previous interaction
- Preferred language

## Activities

- Define customer context.
- Define lookup source.
- Define data required.
- Implement lookup.
- Map response.
- Define failure behaviour.
- Test scenarios.

## Acceptance Criteria

Customer context is retrieved and applied correctly.

## Definition of Done

Customer-context logic is configured and tested.
