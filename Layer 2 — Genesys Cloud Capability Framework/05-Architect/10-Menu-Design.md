# Layer 2.05.10 — Menu Design

## Purpose

Define IVR menus that efficiently direct customers to the correct outcome.

## Classification

**Required**

## Design Principles

- Minimise menu depth.
- Use clear language.
- Avoid unnecessary options.
- Provide repeat functionality.
- Provide agent escalation.
- Provide error handling.
- Consider speech and DTMF.

## Activities

- Identify menu requirements.
- Design menu hierarchy.
- Define prompts.
- Define input options.
- Define invalid input.
- Define timeout.
- Define escape routes.
- Build menus.
- Test.

## Acceptance Criteria

Menus are intuitive and route customers correctly.

## Definition of Done

Menu structure passes usability and functional testing.
