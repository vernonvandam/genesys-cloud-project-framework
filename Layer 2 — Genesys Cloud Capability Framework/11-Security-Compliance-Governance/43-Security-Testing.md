# Layer 2.11.43 — Security Testing

## Purpose

Validate that security controls operate as designed.

## Classification

**Required**

## Activities

- Develop security test plan.
- Test authentication.
- Test SSO.
- Test MFA.
- Test RBAC.
- Test divisions.
- Test privileged access.
- Test API access.
- Test sensitive data.
- Test audit.
- Test monitoring.
- Record defects.
- Retest.

## Definition of Done

Critical security test cases pass.
