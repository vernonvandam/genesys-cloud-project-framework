# Layer 2.11.44 — Compliance Testing

## Purpose

Validate that required compliance controls are implemented.

## Classification

**Required**

## Activities

- Create compliance test matrix.
- Map requirements to tests.
- Execute tests.
- Capture evidence.
- Identify gaps.
- Remediate.
- Retest.
- Obtain approval.

## Definition of Done

Applicable compliance controls are tested and accepted.
