# Layer 2.04.06 — Routing Methods

## 1. Purpose

Select and configure the appropriate Genesys Cloud routing method for each queue.

## 2. Classification

**Required**

## 3. Considerations

Evaluate available routing methods and customer requirements, including:

- Standard routing
- Skills-based routing
- Preferred-agent behaviour
- Bullseye expansion
- Utilisation
- Agent availability
- Service level
- Operational simplicity

## 4. Activities

- Define routing method per queue.
- Document rationale.
- Configure routing.
- Test eligible agents.
- Test unavailable agents.
- Test competing interactions.
- Test priority behaviour.

## 5. Acceptance Criteria

The selected routing method produces the expected agent selection.

## 6. Definition of Done

Routing methods are documented, configured and tested.
