# Layer 2.04.13 — Priority & Interaction Prioritisation

## 1. Purpose

Define how interaction priority affects the order in which interactions are delivered.

## 2. Classification

**Required**

## 3. Discovery

Determine:

- VIP customers
- Service levels
- Business critical interactions
- Emergency interactions
- Customer tiers
- Queue priority
- Interaction priority

## 4. Activities

- Define priority model.
- Define priority calculation.
- Configure priorities.
- Test competing interactions.
- Validate expected ordering.
- Validate reporting.

## 5. Acceptance Criteria

Higher-priority interactions are handled according to approved business rules.

## 6. Definition of Done

Priority model is configured, tested and approved.
