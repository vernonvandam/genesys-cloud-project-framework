# Layer 2.04.14 — Routing Evaluation Criteria

## 1. Purpose

Define the attributes Genesys Cloud evaluates when determining interaction eligibility.

## 2. Classification

**Required**

## 3. Potential Criteria

- Queue
- Skills
- Proficiency
- Language
- Priority
- Agent status
- Utilisation
- Preferred agent
- Routing ring
- Interaction type
- Customer attributes

## 4. Activities

- Identify routing criteria.
- Define evaluation sequence.
- Define fallback.
- Document exceptions.
- Configure logic.
- Test combinations.

## 5. Acceptance Criteria

Routing decisions are predictable, explainable and aligned with business requirements.

## 6. Definition of Done

Evaluation criteria and routing precedence are documented and tested.
