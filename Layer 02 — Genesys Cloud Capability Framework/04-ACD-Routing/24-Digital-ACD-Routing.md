# Layer 2.04.24 — Digital ACD Routing

## 1. Purpose

Define routing of digital interactions into appropriate queues and agents.

## 2. Classification

**Conditional**

## 3. Scope

Potential channels include:

- Web messaging
- Web chat where applicable
- Social messaging
- Other supported digital channels

## 4. Activities

- Identify digital channels.
- Define queues.
- Define routing criteria.
- Define agent capacity.
- Configure routing.
- Test digital delivery.
- Test concurrency.
- Test overflow.

## 5. Acceptance Criteria

Digital interactions reach appropriate agents according to approved routing rules.

## 6. Definition of Done

Digital ACD routing is configured and validated.
