# Layer 2.04.19 — Overflow & Alternate Routing

## 1. Purpose

Define routing when the preferred queue or agent group cannot handle the interaction within expected conditions.

## 2. Classification

**Required**

## 3. Scenarios

- Queue capacity exceeded
- No agents available
- Excessive wait
- Service-level threshold
- Business hours
- System failure
- Skill unavailable
- Site unavailable

## 4. Activities

- Identify overflow triggers.
- Define alternate destinations.
- Define customer messaging.
- Configure overflow.
- Test each trigger.
- Validate fallback.

## 5. Acceptance Criteria

Every defined overflow condition produces the approved outcome.

## 6. Definition of Done

Overflow and alternate routing are configured and tested.
