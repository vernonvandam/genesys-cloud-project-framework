# Layer 2.04.17 — In-Queue Flows

## 1. Purpose

Define the customer experience while an interaction is waiting for an agent.

## 2. Classification

**Required**

## 3. Scope

- Queue announcements
- Music
- Prompts
- Estimated wait
- Position
- Callback
- Self-service
- Queue exit
- Overflow

## 4. Activities

- Define waiting experience.
- Define announcements.
- Define prompts.
- Define callback options.
- Define queue exit conditions.
- Configure in-queue flows.
- Test waiting scenarios.

## 5. Acceptance Criteria

Customers receive the approved experience while waiting.

## 6. Definition of Done

In-queue flows are configured and tested.
