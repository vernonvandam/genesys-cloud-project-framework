# Layer 2.04.09 — Bullseye Routing

## 1. Purpose

Define progressive expansion of the eligible agent pool when the preferred routing group cannot accept an interaction within the required period.

## 2. Classification

**Conditional**

## 3. Discovery

Determine:

- Initial agent group
- Expansion intervals
- Secondary skill requirements
- Maximum expansion
- Business impact
- Service-level requirements

## 4. Activities

- Define bullseye rings.
- Define expansion criteria.
- Configure rings.
- Test initial routing.
- Test ring expansion.
- Test maximum expansion.
- Validate reporting.

## 5. Risks

Incorrect expansion can cause interactions to be delivered to agents without appropriate qualifications.

## 6. Acceptance Criteria

Bullseye routing expands the eligible pool according to approved rules.

## 7. Definition of Done

Bullseye configuration and test scenarios pass.
