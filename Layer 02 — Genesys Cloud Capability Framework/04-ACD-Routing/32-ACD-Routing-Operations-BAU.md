# Layer 2.04.32 — ACD Routing Operations & BAU

## 1. Purpose

Establish the operational model for maintaining and supporting ACD routing after deployment.

## 2. Classification

**Required**

## 3. Scope

- Queue management
- Queue membership
- Skill management
- Routing changes
- Priority changes
- Schedule changes
- Holiday changes
- Troubleshooting
- Monitoring
- Reporting
- Change management
- Incident management
- Performance optimisation

## 4. Activities

- Define support ownership.
- Define L1/L2/L3 responsibilities.
- Define queue-change process.
- Define skill-change process.
- Define routing-change process.
- Define emergency change process.
- Define monitoring.
- Define reporting.
- Create runbooks.
- Train support teams.

## 5. Deliverables

- ACD operations runbook
- Queue administration procedure
- Skill administration procedure
- Routing change procedure
- Troubleshooting guide
- Escalation matrix
- Monitoring procedure
- Holiday maintenance procedure

## 6. Acceptance Criteria

Operations can independently manage standard routing changes and troubleshoot common routing issues.

## 7. Definition of Done

ACD routing support, documentation, ownership and training are complete.
