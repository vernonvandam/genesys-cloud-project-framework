# Layer 2.04.02 — Interaction Routing Strategy

## 1. Purpose

Define how Genesys Cloud determines where every interaction should be routed.

## 2. Classification

**Required**

## 3. Routing Criteria

Potential criteria include:

- DNIS
- ANI
- Customer identity
- Account
- Language
- Skill
- Customer priority
- Interaction priority
- Business function
- Product
- Geography
- Time
- Agent availability
- Previous agent
- Preferred agent
- Channel

## 4. Activities

- Identify routing inputs.
- Define routing decision hierarchy.
- Define routing rules.
- Define exceptions.
- Define fallback.
- Define overflow.
- Define reporting requirements.
- Document routing matrix.

## 5. Acceptance Criteria

All approved interaction types have a deterministic routing strategy.

## 6. Definition of Done

Routing strategy is documented and approved.
