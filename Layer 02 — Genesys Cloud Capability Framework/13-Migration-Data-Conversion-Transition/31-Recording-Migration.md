# Layer 2.13.31 — Recording Migration

## Capability Definition

Recording Migration addresses the migration, preservation or archival of legacy voice and digital recordings.

---

# 1. Scope

- Voice recordings
- Digital recordings
- Recording metadata
- Compliance recordings
- Retention
- Legal holds
- Archive access

---

# 2. Classification

**Conditional**

# 4. Design Activities
