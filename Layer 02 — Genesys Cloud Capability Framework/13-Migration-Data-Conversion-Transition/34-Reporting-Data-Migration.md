# Layer 2.13.34 — Reporting Data Migration

## Capability Definition

Reporting Data Migration preserves or transforms historical reporting data required for continuity of operational, management and regulatory reporting.

---

# 1. Scope

- Historical reports
- KPI history
- Contact centre metrics
- Agent metrics
- Queue metrics
- Management reporting
- Data warehouse

---

# 2. Classification

**Conditional**

---

# 3. Discovery Activities

Identify historical reports, datasets, consumers and retention requirements.

---

# 4. Design Activities

Define migration, archive or warehouse strategy.
