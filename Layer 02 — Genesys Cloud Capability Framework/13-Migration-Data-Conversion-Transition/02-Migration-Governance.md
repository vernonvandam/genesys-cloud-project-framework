# Layer 2.13.02 — Migration Governance

## Capability Definition

Migration Governance establishes the controls, decision rights, ownership, approvals, reporting and quality controls required to manage migration activities.

---

# 1. Scope

- Migration governance
- Decision rights
- Data ownership
- Migration approvals
- Change control
- Migration risks
- Migration issues
- Migration status reporting
- Quality gates
- Evidence management

---

# 2. Classification

**Required**

---

# 3. Discovery Activities

- Identify migration stakeholders.
- Identify source-system owners.
- Identify data owners.
- Identify approval authorities.
- Identify customer governance standards.
- Identify regulatory obligations.
- Identify existing migration governance.

---

# 4. Design Activities

- Define migration RACI.
- Define migration governance forums.
- Define approval gates.
- Define migration reporting.
- Define risk and issue management.
- Define data-quality governance.
- Define change-control requirements.
- Define escalation paths.

# 6. Dependencies

- Migration Strategy
- Project Governance
- Data Ownership
- Security and Compliance
- Cutover Planning

---

# 7. Layer 1 Mapping

Primary:

- Phase 1 — Project Initiation & Mobilisation
- Phase 2 — Discovery & Current State Assessment
- Phase 3 — Requirements & Solution Definition
- Phase 4 — Solution Architecture & Detailed Design
- Phase 7 — Integration & Data Migration
- Phase 9 — Operational Readiness & Cutover Preparation
- Phase 12 — BAU Handover & Project Closure

---

# 8. Roles

- Project Manager
- Migration Lead
- Data Owner
- Solution Architect
- Business SME
- Security Specialist
- Compliance Specialist

---

# 9. Customer Responsibilities

- Nominate migration decision makers.
- Approve RACI.
- Approve governance gates.
- Participate in migration governance.
- Approve migration exceptions.

---

# 10. Testing

Verify that migration decisions, approvals and exceptions are traceable to approved governance records.

---

# 11. Deliverables

- Migration RACI
- Migration Governance Model
- Approval Matrix
- Migration RAID Register
- Migration Status Report

---

# 12. Effort Drivers

Stakeholder count, governance complexity, regulatory controls, number of migration waves and number of source systems.

---

# 13. Acceptance Criteria

- RACI approved.
- Governance forums established.
- Approval gates documented.
- RAID controls established.
- Reporting mechanism established.

---

# 14. Definition of Done

Migration governance is established and operating for the duration of migration activities.
