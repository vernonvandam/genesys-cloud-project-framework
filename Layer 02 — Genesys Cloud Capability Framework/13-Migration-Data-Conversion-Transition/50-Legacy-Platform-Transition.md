# Layer 2.13.50 — Legacy Platform Transition

## Capability Definition

Legacy Platform Transition manages the controlled movement from the legacy contact centre platform to Genesys Cloud and prepares the legacy platform for retirement.

---

# 1. Scope

- Legacy operations
- Coexistence
- Data retention
- Archival
- Decommissioning
- Contracts
- Licences
- Support
- Business acceptance

---

# 2. Classification

**Required**

---

# 3. Discovery Activities

Identify legacy dependencies, users, integrations, data, contracts and operational requirements.

---

# 4. Design Activities

Define transition milestones, retirement conditions and residual dependencies.

---

# 5. Implementation Activities

| Task ID | Task | Phase | Effort |
|---|---|---|---:|
| 2.13.50-T01 | Inventory legacy dependencies | Phase 2 | 5h |
| 2.13.50-T02 | Define transition plan | Phase 4 | 5h |
| 2.13.50-T03 | Execute transition | Phase 10 | 6h |
| 2.13.50-T04 | Validate residual dependencies | Phase 11 | 5h |
| 2.13.50-T05 | Approve legacy retirement | Phase 12 | 2h |

---

# 6. Dependencies

- Migration
- Coexistence
- Archival
- Decommissioning

# 7. Layer 1 Mapping

Approve legacy transition and retirement.

---

# 10. Testing

Validate that no production dependencies remain.

---

- Dependency Validation
- Retirement Approval

---

# 12. Effort Drivers

Legacy complexity and contractual dependencies.

---

# 13. Acceptance Criteria

---

# 14. Definition of Done

Legacy transition is approved.
