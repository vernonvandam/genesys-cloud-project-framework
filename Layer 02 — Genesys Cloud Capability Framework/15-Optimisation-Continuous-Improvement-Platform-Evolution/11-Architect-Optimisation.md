# Layer 2.15.11 — Architect Optimisation

## Capability Definition

Optimises Genesys Cloud Architect flows to improve customer journeys, maintainability, automation, integration performance, error handling and operational outcomes.

---

# 1. Scope

- Inbound flows
- IVR
- In-queue flows
- Data actions
- Common modules
- Error handling
- Flow performance
- Flow governance

# 2. Classification

**Required**

- Review flow complexity.

- Simplify flow logic.
- Optimise data actions.
- Improve error handling.
- Define flow governance.
