# Layer 2.15.39 — Pilot Management

## Capability Definition

Provides controlled introduction of new Genesys Cloud capabilities or optimisation changes to a limited population before wider adoption.

---

# 1. Scope

- Pilot scope
- Pilot users
- Pilot governance
- Success criteria
- Feedback
- Measurement
- Pilot exit

---

# 2. Classification

**Conditional**

---

# 3. Discovery Activities

- Identify pilot objective.
- Select pilot users.
- Identify risks.
- Define baseline.
- Identify dependencies.

---

# 4. Design Activities

- Define pilot scope.
- Define success criteria.
- Define pilot duration.
- Define feedback mechanisms.
- Define rollback criteria.
- Define expansion criteria.
