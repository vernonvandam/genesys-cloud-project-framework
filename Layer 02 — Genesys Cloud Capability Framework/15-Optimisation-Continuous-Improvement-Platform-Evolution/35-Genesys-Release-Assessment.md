# Layer 2.15.35 — Genesys Release Assessment

## Capability Definition

Provides a structured process for assessing Genesys Cloud releases, product changes and new functionality for business impact, risk, compatibility and adoption.

---

# 1. Scope

- Release monitoring
- Release assessment
- Impact analysis
- Feature evaluation
- Regression impact
- Change planning
- Adoption decisions

---

# 2. Classification

**Required**

---

# 3. Discovery Activities

- Review Genesys release information.
- Identify affected capabilities.
- Identify affected integrations.
- Identify affected processes.
- Identify potential risks.

---

# 4. Design Activities

- Define release assessment process.
- Define impact categories.
- Define decision criteria.
- Define testing requirements.
- Define communication process.
- Define adoption workflow.
