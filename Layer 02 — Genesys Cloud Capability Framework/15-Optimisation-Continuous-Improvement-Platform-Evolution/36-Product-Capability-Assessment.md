# Layer 2.15.36 — Product Capability Assessment

## Capability Definition

Assesses Genesys Cloud capabilities against business requirements, maturity, value, adoption potential and strategic fit.

---

# 1. Scope

- Capability assessment
- Business fit
- Technical fit
- Feature maturity
- Value assessment
- Adoption readiness

---

# 2. Classification

**Required**

---

# 3. Discovery Activities

- Identify relevant capabilities.
- Review business requirements.
- Assess current functionality.
- Identify capability gaps.
- Review strategic relevance.

---

# 4. Design Activities

- Define assessment framework.
- Define scoring criteria.
- Define business value criteria.
- Define technical fit criteria.
- Define recommendation process.
