# Layer 2.15.10 — Routing Optimisation

## Capability Definition

Optimises interaction routing to improve service level, customer experience, agent utilisation, skill matching and operational efficiency.

---

# 1. Scope

- ACD routing
- Skills
- Queues
- Bullseye routing
- Preferred agents
- Priority
- Overflow
- Routing performance

---

# 2. Classification

**Required**

---

# 3. Discovery Activities

- Review routing architecture.
- Analyse routing outcomes.
- Review queue performance.
- Analyse skill utilisation.
- Review overflow behaviour.
- Identify routing inefficiencies.

---

# 4. Design Activities

- Define routing objectives.
- Optimise queue strategy.
- Review skills.
- Design routing rules.
- Define routing performance thresholds.
