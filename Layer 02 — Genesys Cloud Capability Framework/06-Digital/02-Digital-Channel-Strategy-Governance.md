# Layer 2.06.02 — Digital Channel Strategy & Governance

## Purpose

Establish governance over the digital channel portfolio.

## Classification

**Required**

## Activities

- Define channel ownership.
- Define supported channels.
- Define channel eligibility.
- Define operating hours.
- Define service levels.
- Define content standards.
- Define security requirements.
- Define change management.
- Define channel retirement criteria.
- Define support ownership.

## Deliverables

- Digital channel strategy
- Channel governance standard
- Channel ownership matrix

## Acceptance Criteria

Every production channel has a defined owner and support model.

## Definition of Done

Digital governance is formally approved.
