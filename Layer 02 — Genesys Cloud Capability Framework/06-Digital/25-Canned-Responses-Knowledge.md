# Layer 2.06.25 — Canned Responses & Knowledge

## Purpose

Improve agent efficiency and consistency when responding to digital customers.

## Classification

**Required**

## Scope

- Canned responses
- Templates
- Standard responses
- Knowledge content
- Regulatory language
- Escalation responses

## Activities

- Identify common interactions.
- Create response catalogue.
- Define ownership.
- Define approval.
- Configure responses.
- Validate content.
- Test agent usage.
- Establish review cycle.

## Acceptance Criteria

Approved responses are available to agents and use appropriate customer language.

## Definition of Done

Canned-response catalogue is operational and governed.
