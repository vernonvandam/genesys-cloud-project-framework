# Layer 2.06.05 — Web Chat

## Purpose

Support legacy or synchronous web-chat requirements where applicable.

## Classification

**Conditional**

## Activities

- Assess requirement.
- Determine whether Web Messaging is preferable.
- Define chat entry point.
- Define agent availability.
- Configure routing.
- Configure queue.
- Configure chat experience.
- Test concurrent sessions.
- Test transfer.
- Test disconnect.

## Acceptance Criteria

The selected web-chat architecture satisfies business requirements.

## Definition of Done

Web chat is configured or formally determined not to be required.
