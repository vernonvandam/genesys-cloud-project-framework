# Layer 2.06.17 — Digital Authentication

## Purpose

Authenticate customers where required before accessing protected information or functionality.

## Classification

**Conditional**

## Scope

- Anonymous users
- Authenticated users
- Customer identity
- Verification
- Session state
- Account lookup
- Secure escalation

## Activities

- Identify protected journeys.
- Define authentication requirement.
- Define identity provider where applicable.
- Define verification.
- Define session behaviour.
- Configure.
- Test successful authentication.
- Test failure.
- Test session expiry.

## Acceptance Criteria

Protected digital journeys cannot be accessed without the required authentication.

## Definition of Done

Authentication passes security and functional testing.
