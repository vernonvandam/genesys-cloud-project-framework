# Layer 2.06.23 — Digital Attachments

## Purpose

Support file exchange through approved digital channels.

## Classification

**Conditional**

## Activities

- Identify attachment requirements.
- Define supported file types.
- Define size limits.
- Define security requirements.
- Define malware scanning.
- Define retention.
- Configure.
- Test upload.
- Test download.
- Test invalid file.

## Acceptance Criteria

Attachments comply with approved security and operational policies.

## Definition of Done

Attachment functionality is production-ready.
