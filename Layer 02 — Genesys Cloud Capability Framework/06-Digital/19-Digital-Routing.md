# Layer 2.06.19 — Digital Routing

## Purpose

Route digital interactions to the appropriate service destination.

## Classification

**Required**

## Routing Inputs

- Channel
- Customer type
- Intent
- Language
- Product
- Skills
- Queue
- Priority
- SLA
- Customer context
- Agent availability

## Activities

- Define routing matrix.
- Map queues.
- Map skills.
- Define priority.
- Define fallback.
- Configure routing.
- Test routing combinations.
- Validate with ACD team.

## Acceptance Criteria

Digital interactions reach the intended destination.

## Definition of Done

Routing is fully tested.
