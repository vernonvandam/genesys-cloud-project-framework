# Layer 2.06.26 — Agent Digital Workspace

## Purpose

Ensure agents can efficiently manage digital interactions.

## Classification

**Required**

## Scope

- Digital interaction view
- Customer context
- Conversation history
- Attachments
- Canned responses
- Customer information
- Transfer
- Wrap-up
- Disposition

## Activities

- Define agent journey.
- Configure agent permissions.
- Configure queues.
- Configure skills.
- Configure scripts/workspace elements.
- Validate customer context.
- Test concurrent digital interactions where applicable.
- Test transfer.
- Test wrap-up.

## Acceptance Criteria

Agents can handle digital interactions according to the approved operating model.

## Definition of Done

Agent digital workspace passes UAT.
