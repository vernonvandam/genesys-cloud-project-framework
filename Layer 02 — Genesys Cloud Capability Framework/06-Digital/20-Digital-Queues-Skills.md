# Layer 2.06.20 — Digital Queues & Skills

## Purpose

Provide the ACD destinations required for digital service.

## Classification

**Required**

## Activities

- Identify digital service groups.
- Determine queue structure.
- Determine skills.
- Map agents.
- Define language skills.
- Define product skills.
- Define queue ownership.
- Test queue entry.
- Test agent availability.

## Acceptance Criteria

All digital interactions can be delivered to the appropriate service group.

## Definition of Done

Digital queue and skill configuration is operational.
