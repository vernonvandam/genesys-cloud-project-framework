# Layer 2.06.36 — Digital Governance & Lifecycle

## Purpose

Govern the lifecycle of digital channels from introduction through retirement.

## Classification

**Required**

## Lifecycle

```text

  ▼

```

## Activities

- Define channel lifecycle.
- Define ownership.
- Define review cadence.
- Define change process.
- Define content review.
- Define security review.
- Define performance review.
- Define retirement criteria.
- Maintain channel inventory.

## Acceptance Criteria

Every digital channel has an owner, lifecycle status and review process.

## Definition of Done

Digital governance is operational.
