# Layer 2.06.04 — Web Messenger Deployment

## Purpose

Deploy the Genesys Cloud web messaging experience into supported web properties.

## Classification

**Required**

## Activities

1. Identify websites/applications.
2. Identify web environments.
3. Define deployment architecture.
4. Configure Messenger.
5. Define branding.
6. Configure deployment.
7. Configure security.
8. Validate domains.
9. Test desktop.
10. Test mobile.
11. Test authenticated and anonymous journeys.
12. Validate production deployment.

## Acceptance Criteria

Web Messenger loads correctly and provides the approved customer experience.

## Definition of Done

Web Messenger is deployed and validated in production.
