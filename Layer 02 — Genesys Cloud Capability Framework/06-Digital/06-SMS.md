# Layer 2.06.06 — SMS

## Purpose

Provide SMS-based customer engagement.

## Classification

**Conditional**

## Scope

- SMS numbers
- Inbound SMS
- Outbound SMS
- Messaging routing
- Customer identity
- Queue
- Agent
- Opt-in/opt-out
- Compliance

## Activities

- Determine SMS use cases.
- Acquire/configure messaging numbers.
- Define ownership.
- Define routing.
- Define opt-in/opt-out requirements.
- Configure SMS.
- Test inbound.
- Test outbound.
- Test customer escalation.
- Validate compliance.

## Acceptance Criteria

SMS interactions route and operate correctly.

## Definition of Done

SMS is operational with required compliance controls.
