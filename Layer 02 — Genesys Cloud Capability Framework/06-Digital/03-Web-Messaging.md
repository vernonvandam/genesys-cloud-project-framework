# Layer 2.06.03 — Web Messaging

## Purpose

Provide customer-initiated web messaging through the Genesys Cloud digital experience.

## Classification

**Required**

## Scope

- Customer entry point
- Web Messenger
- Authentication
- Customer context
- Bot
- Queue
- Agent
- Conversation continuation
- Conversation termination

## Activities

- Define web messaging use cases.
- Define entry points.
- Configure messaging deployment.
- Define routing.
- Configure bot integration where required.
- Configure queue.
- Configure agent handling.
- Test customer journey.
- Test escalation.
- Test out-of-hours behaviour.

## Acceptance Criteria

Customers can initiate and complete approved web messaging journeys.

## Definition of Done

Web messaging is production-ready.
