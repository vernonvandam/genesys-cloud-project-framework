# Layer 2.05.31 — Flow Security & Sensitive Data

## Purpose

Ensure Architect flows protect sensitive information.

## Classification

**Required**

## Scope

- Sensitive data
- Authentication
- PCI-related requirements where applicable
- Data exposure
- Logging
- Variable handling
- Secure flow patterns
- Access control
- Integration credentials

## Activities

- Identify sensitive data.
- Classify data.
- Define security controls.
- Define secure flow requirements.
- Review Data Actions.
- Review prompts.
- Review variables.
- Execute security review.
- Remediate findings.

## Acceptance Criteria

Security requirements are satisfied before production.

## Definition of Done

Architect flows pass security review.
