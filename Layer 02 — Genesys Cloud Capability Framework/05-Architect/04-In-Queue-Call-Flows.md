# Layer 2.05.04 — In-Queue Call Flows

## Purpose

Provide customer interaction handling while waiting for an agent.

## Classification

**Conditional**

## Scope

- Queue announcements
- Music
- Estimated wait
- Position
- Self-service
- Callback
- Queue exit
- Overflow

## Activities

- Define queue experience.
- Define prompts.
- Define self-service opportunities.
- Define callback.
- Configure flow.
- Test queue states.
- Test overflow.
- Test callback.

## Acceptance Criteria

The approved waiting experience operates correctly.

## Definition of Done

In-queue flows are configured and validated.
