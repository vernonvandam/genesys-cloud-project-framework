# Layer 2.05.33 — Flow Versioning & Promotion

## Purpose

Control Architect flow versions throughout the development lifecycle.

## Classification

**Required**

## Environment Model

```text
DEV
 │
 ▼
TEST / SIT
 │
 ▼
UAT
 │
 ▼
PRODUCTION
```

## Activities

- Define versioning standard.
- Define development ownership.
- Define release naming.
- Create development version.
- Test version.
- Lock approved version.
- Approve release.
- Promote to production.
- Record deployment.

## Acceptance Criteria

The production version is traceable to the approved tested version.

## Definition of Done

Version and promotion process is documented and repeatable.
