# Layer 2.05.11 — IVR Navigation

## Purpose

Define how customers navigate the IVR using speech and/or keypad input.

## Classification

**Required**

## Scope

- Main menu
- Submenus
- Back
- Repeat
- Main menu
- Agent
- Exit
- Invalid input
- Timeout

## Activities

- Define navigation model.
- Define navigation shortcuts.
- Define escape options.
- Configure navigation.
- Test all paths.
- Test invalid inputs.
- Test timeout.

## Acceptance Criteria

Customers can navigate every approved IVR path.

## Definition of Done

Navigation behaviour is tested and approved.
