# Layer 2.05.22 — Authentication & Verification

## Purpose

Verify customer identity before exposing protected information or performing sensitive actions.

## Classification

**Conditional**

## Potential Methods

- Customer number
- PIN
- Knowledge-based verification
- Account information
- External authentication
- One-time verification mechanisms where supported

## Activities

- Define authentication policy.
- Define data requirements.
- Define retry limits.
- Define lockout/failure behaviour.
- Configure verification.
- Test successful authentication.
- Test failed authentication.
- Test escalation.

## Acceptance Criteria

Authentication meets approved security requirements.

## Definition of Done

Authentication flow passes security and functional testing.
