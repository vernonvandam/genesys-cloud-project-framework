# Layer 2.09.38 — Data Extraction & Export

## Purpose

Provide controlled extraction of reporting data.

## Classification

**Required**

## Activities

- Identify extraction requirements.
- Define source.
- Define format.
- Define frequency.
- Define volume.
- Define retention.
- Define security.
- Configure extraction.
- Validate.
- Reconcile.

## Definition of Done

Required reporting data can be exported reliably and securely.
