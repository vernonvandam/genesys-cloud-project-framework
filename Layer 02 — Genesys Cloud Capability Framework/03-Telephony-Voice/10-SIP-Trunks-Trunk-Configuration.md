# Layer 2.03.10 — SIP Trunks & Trunk Configuration

## 1. Purpose

Configure SIP trunks required for customer voice connectivity.

## 2. Classification

**Conditional**

## 3. Discovery

Determine:

- Carrier
- Trunk model
- Signalling
- Media
- Authentication
- TLS/SRTP requirements
- Codec
- Caller ID
- Number ranges
- Redundancy

## 4. Activities

- Define trunk architecture.
- Configure trunk.
- Configure carrier parameters.
- Configure media parameters.
- Configure number associations.
- Validate registration/connectivity.
- Test inbound.
- Test outbound.
- Test failure scenarios.

## 5. Acceptance Criteria

SIP trunks operate reliably for all approved scenarios.

## 6. Definition of Done

Trunks are configured, tested and documented.
