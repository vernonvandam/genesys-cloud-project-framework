# Layer 2.03.03 — Carrier & SIP Connectivity

## 1. Purpose

Design and implement connectivity between Genesys Cloud and the PSTN/carrier environment.

## 2. Classification

**Required for PSTN voice deployments**

## 3. Discovery

Identify:

- Carrier
- SIP provider
- Existing trunks
- Number ranges
- Inbound routes
- Outbound routes
- Calling line identity
- Codec requirements
- SIP transport
- Security
- Redundancy
- Carrier SLAs
- Support model

## 4. Activities

- Confirm carrier.
- Confirm supported architecture.
- Validate carrier prerequisites.
- Define SIP requirements.
- Define network requirements.
- Configure connectivity.
- Validate signalling.
- Validate media.
- Validate inbound calling.
- Validate outbound calling.
- Validate caller ID.
- Document carrier support model.

## 5. Dependencies

- Telephony model
- Network
- Firewall
- Numbers
- Carrier

## 6. Risks

- Carrier configuration delays.
- SIP incompatibility.
- Incorrect media routing.
- Caller ID restrictions.

## 7. Deliverables

- Carrier design
- SIP configuration
- Carrier test results
- Carrier escalation information

## 8. Acceptance Criteria

Carrier connectivity supports the approved inbound and outbound voice scenarios.

## 9. Definition of Done

Carrier connectivity is operational, tested and documented.
