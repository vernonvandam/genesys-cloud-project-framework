# Layer 2.03.31 — Telephony Migration & Cutover

## 1. Purpose

Plan and execute the transition from the existing telephony environment to Genesys Cloud.

## 2. Classification

**Conditional**

Required for migrations from existing telephony platforms.

## 3. Discovery

Determine:

- Current platform
- Number inventory
- Porting requirements
- Carrier dependencies
- Business critical numbers
- Cutover windows
- Freeze periods
- Rollback options
- Communications
- Support staffing

## 4. Activities

### Planning

- Define cutover strategy.
- Define migration waves.
- Define cutover sequence.
- Define rollback.
- Define communications.
- Define support model.

### Preparation

- Validate target configuration.
- Validate numbers.
- Validate routing.
- Validate carrier.
- Validate endpoints.
- Execute dress rehearsal.

### Cutover

- Initiate change window.
- Execute number migration.
- Activate target routing.
- Validate inbound.
- Validate outbound.
- Validate critical numbers.
- Monitor calls.

### Post-Cutover

- Monitor traffic.
- Resolve defects.
- Validate business services.
- Confirm customer acceptance.
- Close change.

## 5. Acceptance Criteria

Production telephony operates successfully after cutover with no unresolved critical issues.

## 6. Definition of Done

Migration is completed, validated and formally accepted.
