# Layer 2.03.29 — Voice Security & Compliance

## 1. Purpose

Ensure telephony architecture complies with security, privacy and regulatory requirements.

## 2. Classification

**Required**

## 3. Scope

- SIP security
- TLS
- SRTP
- Network security
- Caller identity
- Call recording
- Sensitive data
- Emergency services
- Fraud prevention
- International calling
- Premium numbers
- Access control

## 4. Activities

- Identify security requirements.
- Identify regulatory requirements.
- Review carrier security.
- Review media security.
- Review network security.
- Define outbound restrictions.
- Define privileged access.
- Validate recording implications.
- Obtain security approval.

## 5. Risks

- Toll fraud.
- Unauthorised international calling.
- Sensitive information exposure.
- Inadequate recording controls.
- Incorrect emergency calling.

## 6. Acceptance Criteria

Voice architecture complies with approved customer security and regulatory requirements.

## 7. Definition of Done

Security and compliance requirements are validated and approved.
