# Layer 2.03.08 — Edges & Telephony Devices

## 1. Purpose

Define Edge and telephony-device requirements where applicable.

## 2. Classification

**Conditional**

## 3. Discovery

Determine:

- BYOC Premises requirements
- Edge locations
- Hardware requirements
- Network connectivity
- Redundancy
- Device ownership
- Maintenance
- Replacement strategy

## 4. Activities

- Identify required Edge devices.
- Validate hardware requirements.
- Prepare network.
- Deploy devices.
- Configure devices.
- Validate registration.
- Validate media.
- Test failure scenarios.
- Document support.

## 5. Acceptance Criteria

Required Edge infrastructure is operational and resilient according to the approved design.

## 6. Definition of Done

Edges are deployed, configured, tested and documented.
