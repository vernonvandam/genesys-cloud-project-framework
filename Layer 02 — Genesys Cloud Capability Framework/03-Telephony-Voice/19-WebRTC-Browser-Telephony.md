# Layer 2.03.19 — WebRTC & Browser Telephony

## 1. Purpose

Define and validate browser-based agent telephony.

## 2. Classification

**Required for browser-based agent voice**

## 3. Discovery

Determine:

- Supported browser
- Desktop standards
- Headset standards
- Microphone permissions
- Speaker permissions
- Network policies
- Browser security restrictions
- Agent workstation standards

## 4. Activities

- Validate supported browser.
- Validate workstation configuration.
- Validate microphone access.
- Validate speaker access.
- Validate headset.
- Test inbound call.
- Test outbound call.
- Test hold.
- Test transfer.
- Test conference.
- Test disconnect/reconnect.
- Validate browser behaviour.

## 5. Risks

- Browser permissions.
- Unsupported browser.
- Endpoint driver issues.
- Poor workstation audio.

## 6. Acceptance Criteria

Agents can reliably conduct approved voice workflows using the browser.

## 7. Definition of Done

WebRTC telephony is validated across supported agent workstation profiles.
