# Layer 2.03.07 — Sites

## 1. Purpose

Define Genesys Cloud site architecture for geographic and telephony configuration.

## 2. Classification

**Required**

## 3. Discovery

Determine:

- Physical locations
- Agent locations
- Network topology
- Telephony model
- Edge requirements
- Site-specific number ranges
- Regional requirements
- Media requirements

## 4. Activities

1. Define site inventory.
2. Define site naming.
3. Map locations.
4. Determine site telephony configuration.
5. Configure sites.
6. Associate required telephony resources.
7. Validate site behaviour.

## 5. Dependencies

- Architecture
- Telephony model
- Network
- Edge architecture

## 6. Acceptance Criteria

All required sites are configured consistently with the approved architecture.

## 7. Definition of Done

Sites are configured, documented and validated.
