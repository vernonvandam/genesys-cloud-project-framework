# Layer 2.03.28 — Telephony Integrations

## 1. Purpose

Define integrations between Genesys Cloud voice services and external telephony platforms.

## 2. Classification

**Conditional**

## 3. Scope

Potential integrations include:

- Carrier platforms
- PBXs
- SIP services
- Recording platforms
- Contact centre applications
- CRM
- CTI
- Call control
- Workforce systems
- Reporting systems
- Emergency services
- Monitoring platforms

## 4. Activities

- Inventory integrations.
- Define integration architecture.
- Define authentication.
- Define media/signalling requirements.
- Configure integration.
- Test call flows.
- Test failure scenarios.
- Document support ownership.

## 5. Acceptance Criteria

All required telephony integrations operate according to approved requirements.

## 6. Definition of Done

Integrations are implemented, tested and operationally documented.
