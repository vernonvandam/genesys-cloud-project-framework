# Layer 2.03.12 — Number Porting & Migration

## 1. Purpose

Manage migration of existing telephone numbers into the target Genesys Cloud telephony architecture.

## 2. Classification

**Conditional**

## 3. Discovery

Determine:

- Numbers to port
- Carrier
- Account owner
- Porting eligibility
- Required documentation
- Porting lead time
- Cutover date
- Temporary routing
- Rollback

## 4. Activities

- Create porting inventory.
- Validate number ownership.
- Gather carrier documentation.
- Submit port request.
- Track port status.
- Validate target configuration.
- Perform pre-port testing.
- Execute port.
- Validate inbound.
- Validate outbound.
- Monitor post-port.
- Close porting activity.

## 5. Risks

- Rejected port.
- Incorrect account details.
- Lost service.
- Porting delay.
- Incorrect target routing.

## 6. Acceptance Criteria

All approved numbers port successfully and route correctly.

## 7. Definition of Done

Porting is complete, validated and accepted.
