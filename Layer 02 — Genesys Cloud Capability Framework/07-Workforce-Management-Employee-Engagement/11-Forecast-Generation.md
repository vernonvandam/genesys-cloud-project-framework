# Layer 2.07.11 — Forecast Generation

## Purpose

Generate operational forecasts for future workload.

## Classification

**Required**

## Activities

1. Select planning group.
2. Select forecast period.
3. Load historical data.
4. Generate forecast.
5. Review forecast.
6. Apply approved adjustments.
7. Document assumptions.
8. Approve forecast.
9. Publish forecast.

## Acceptance Criteria

Forecast is approved and available for staffing calculations.

## Definition of Done

Forecast generation process is operational.
