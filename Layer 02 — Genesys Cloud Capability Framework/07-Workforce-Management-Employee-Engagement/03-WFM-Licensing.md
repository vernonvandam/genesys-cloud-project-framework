# Layer 2.07.03 — WFM Licensing

## Purpose

Validate licensing requirements for all WFM users and capabilities.

## Classification

**Required**

## Activities

- Inventory WFM personas.
- Identify required WFM capabilities.
- Map capabilities to licences.
- Identify supervisor requirements.
- Identify planner requirements.
- Identify agent requirements.
- Identify reporting requirements.
- Identify employee engagement requirements.
- Validate entitlements.
- Document licensing assumptions.

## Acceptance Criteria

All required users and capabilities have appropriate licensing.

## Definition of Done

Licensing is confirmed before configuration begins.
