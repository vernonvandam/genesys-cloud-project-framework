# Layer 2.07.05 — Management Units

## Purpose

Define the operational management structure used for workforce administration.

## Classification

**Required**

## Activities

- Identify supervisory groups.
- Identify agent groups.
- Define management-unit boundaries.
- Map agents.
- Map supervisors.
- Map schedules.
- Define permissions.
- Configure management units.
- Validate.

## Acceptance Criteria

Management units accurately represent operational supervision.

## Definition of Done

Management-unit configuration is complete.
