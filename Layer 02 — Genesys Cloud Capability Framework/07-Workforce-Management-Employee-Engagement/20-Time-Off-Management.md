# Layer 2.07.20 — Time-Off Management

## Purpose

Manage planned employee time away from scheduled work.

## Activities

- Identify time-off categories.
- Define eligibility.
- Define approval rules.
- Define blackout periods where applicable.
- Define capacity constraints.
- Configure time-off categories.
- Test request.
- Test approval.
- Test rejection.
- Validate schedule impact.

## Acceptance Criteria

Time-off requests follow approved workforce rules.

## Definition of Done

Time-off management is operational.
