# Layer 2.07.45 — WFM Continuous Optimisation

## Purpose

Continuously improve forecast accuracy, workforce utilisation, service performance and employee experience.

## Optimisation Areas

- Forecast accuracy
- Staffing accuracy
- Schedule efficiency
- Service level
- Occupancy
- Adherence
- Shrinkage
- Overtime
- Time-off utilisation
- Employee experience
- Self-service
- Intraday response
- Workforce cost

## Activities

- Establish baseline.
- Review forecast accuracy.
- Review staffing variance.
- Review schedule performance.
- Review adherence.
- Review employee feedback.
- Identify optimisation opportunities.
- Implement changes.
- Regression test.
- Measure outcome.
- Update operating model.

## Acceptance Criteria

Optimisation initiatives have measurable business outcomes.

## Definition of Done

WFM optimisation is embedded into BAU governance.
