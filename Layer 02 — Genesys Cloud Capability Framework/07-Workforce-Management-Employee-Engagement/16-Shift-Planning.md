# Layer 2.07.16 — Shift Planning

## Purpose

Define shift patterns used to construct schedules.

## Activities

- Identify shift patterns.
- Identify operating hours.
- Define shift lengths.
- Define break patterns.
- Define skill coverage.
- Define employee constraints.
- Define shift templates.
- Validate against staffing requirement.

## Acceptance Criteria

Shift patterns can support forecast staffing requirements.

## Definition of Done

Shift planning model is approved.
