# Layer 2.07.18 — Schedule Optimisation

## Purpose

Optimise schedules against competing workforce objectives.

## Optimisation Considerations

- Service level
- Coverage
- Agent preferences
- Skills
- Shrinkage
- Break placement
- Employee constraints
- Overtime
- Understaffing
- Overstaffing

## Activities

- Define optimisation objectives.
- Define priority.
- Run optimisation.
- Review results.
- Identify exceptions.
- Apply manual adjustments.
- Validate coverage.

## Acceptance Criteria

Schedule optimisation improves coverage without violating approved workforce constraints.

## Definition of Done

Optimised schedule is approved.
