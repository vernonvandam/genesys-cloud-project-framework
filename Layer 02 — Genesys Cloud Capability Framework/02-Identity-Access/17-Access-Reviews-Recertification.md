# Layer 2.02.17 — Access Reviews & Recertification

## 1. Purpose

Establish ongoing governance to verify that users retain only appropriate access.

## 2. Classification

**Required**

## 3. Discovery

Determine:

- Review frequency.
- Review owners.
- Privileged-access review.
- Agent access review.
- Contractor review.
- API identity review.
- Licence review.
- Division review.
- Evidence requirements.

## 4. Design

Define review cycles:

```text
User Access
     ↓
Manager Review
     ↓
Security Review
     ↓
Exceptions
     ↓
Remediation
     ↓
Evidence
```

## 5. Implementation

- Create review process.
- Identify access reports.
- Establish owners.
- Define remediation.
- Document evidence requirements.

## 6. Acceptance Criteria

Customer can periodically review and remediate access.

## 7. Definition of Done

Access review ownership, frequency, evidence and remediation procedures are established.
