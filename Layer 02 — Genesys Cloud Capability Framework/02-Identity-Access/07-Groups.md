# Layer 2.02.07 — Groups

## 1. Purpose

Define groups used to organise users and support scalable access management.

## 2. Classification

**Required**

The complexity depends on the customer's organisation and security model.

## 3. Discovery

Determine:

- Existing groups.
- Department groups.
- Agent groups.
- Supervisor groups.
- Administrator groups.
- Support groups.
- Geographic groups.
- Security groups.
- IAM group integration.

## 4. Design

Define:

- Naming.
- Ownership.
- Membership.
- Lifecycle.
- Role relationship.
- Division relationship.
- Licence relationship where applicable.

## 5. Implementation

- Create groups.
- Configure membership.
- Map groups to access model.
- Validate inheritance/assignment.
- Test membership changes.

## 6. Dependencies

- IAM
- Roles
- Permissions
- Divisions
- SCIM

## 7. Acceptance Criteria

Groups support the approved access-management model without excessive privilege.

## 8. Definition of Done

Groups are configured, mapped and tested.
