# Layer 2.02.14 — Security & Authentication Policies

## 1. Purpose

Define authentication and security policy requirements governing Genesys Cloud access.

## 2. Classification

**Required**

## 3. Discovery

Determine:

- Password policy requirements where applicable.
- MFA.
- SSO.
- Session controls.
- Authentication restrictions.
- Administrative restrictions.
- Security exceptions.
- Compliance requirements.

## 4. Design

- Define standard policy.
- Define administrator policy.
- Define exception process.
- Define monitoring.
- Define review cycle.

## 5. Implementation

- Configure approved security settings.
- Apply authentication controls.
- Validate policy behaviour.
- Document exceptions.

## 6. Testing

Test:

- Standard users.
- Administrators.
- Invalid authentication.
- MFA.
- Disabled users.
- Exception cases.

## 7. Acceptance Criteria

Security policies meet approved customer and organisational standards.

## 8. Definition of Done

Required security and authentication policies are configured, tested and documented.
