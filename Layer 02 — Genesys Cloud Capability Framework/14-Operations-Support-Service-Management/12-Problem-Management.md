# Layer 2.14.12 — Problem Management

## Capability Definition

Problem Management identifies and removes underlying causes of recurring or significant Genesys Cloud incidents.

---

# 1. Scope

- Problem identification
- Trend analysis
- Root-cause analysis
- Known errors
- Corrective actions
- Permanent fixes
- Problem records
- Post-incident analysis

---

# 2. Classification

**Required**

---

# 3. Discovery Activities

- Review current problem management process.
- Identify recurring incidents.
- Identify known errors.
- Identify root-cause analysis methods.
- Identify problem ownership.

---

# 4. Design Activities

- Define problem identification criteria.
- Define RCA process.
- Define problem prioritisation.
- Define corrective action workflow.
- Define known-error process.
