# Layer 2.14.07 — L2 Support

## Capability Definition

L2 Support provides technical and configuration-level support for Genesys Cloud capabilities beyond first-line troubleshooting.

---

# 1. Scope

- Configuration troubleshooting
- Routing troubleshooting
- Architect troubleshooting
- Telephony troubleshooting
- Digital troubleshooting
- Integration troubleshooting
- Platform administration
- Technical escalation

---

# 2. Classification

**Required**

---

# 3. Discovery Activities

- Identify L2 support capabilities.
- Identify technical SMEs.
- Identify escalation boundaries.
- Identify supported configuration domains.
- Identify tooling and access requirements.

---

# 4. Design Activities

- Define L2 support responsibilities.
- Define technical escalation procedures.
- Define access requirements.
- Define troubleshooting standards.
- Define handoff requirements to L3.

- Access configured.

# 14. Definition of Done
