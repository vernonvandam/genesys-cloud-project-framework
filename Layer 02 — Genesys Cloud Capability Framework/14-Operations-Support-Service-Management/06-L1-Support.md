# Layer 2.14.06 — L1 Support

## Capability Definition

L1 Support defines the first-line operational support capability for Genesys Cloud users and business teams.

---

# 1. Scope

- First-line support
- User assistance
- Basic troubleshooting
- Incident logging
- Knowledge articles
- Initial triage
- Escalation
- User communications

---

# 2. Classification

**Required**

---

# 3. Discovery Activities

- Identify L1 support team.
- Identify supported user groups.
- Identify common incidents.
- Identify support hours.
- Identify escalation requirements.

---

# 4. Design Activities

- Define L1 support responsibilities.
- Define troubleshooting boundaries.
- Define escalation criteria.
- Define knowledge requirements.
- Define L1 operating procedures.

- Procedures approved.

---

# 14. Definition of Done
