# Layer 2.14.03 — BAU Readiness

## Capability Definition

BAU Readiness establishes the operational conditions required for the customer to safely operate Genesys Cloud following project completion.

---

# 1. Scope

- BAU readiness assessment
- Operational processes
- Support readiness
- Administration readiness
- Monitoring readiness
- Documentation
- Training
- Knowledge transfer
- Outstanding defects
- Operational acceptance

---

# 2. Classification

**Required**

---

# 3. Discovery Activities

- Assess current BAU capability.
- Identify operational gaps.
- Identify support gaps.
- Identify training requirements.
- Identify documentation gaps.
- Identify unresolved defects.
- Identify readiness criteria.

---

# 4. Design Activities

- Define BAU readiness criteria.
- Define operational acceptance criteria.
- Define readiness assessment process.
- Define outstanding-risk management.
- Define operational handover requirements.
