# 04 — Requirements Traceability

## Capability Definition

Provides traceability between approved requirements, solution capabilities, test cases, execution evidence, defects and acceptance outcomes.

---

# 1. Scope

- Requirements
- Capability mapping
- Test case mapping
- Defect mapping
- Acceptance mapping
- Test evidence

---

# 2. Classification

**Required**

---

# 3. Discovery Activities

- Identify requirement sources.
- Identify business requirements.
- Identify technical requirements.
- Identify compliance requirements.
- Identify integration requirements.
- Identify acceptance criteria.

---

# 4. Design Activities

- Define traceability structure.
- Define requirement identifiers.
- Define test mapping.
- Define evidence requirements.
- Define defect traceability.
- Define acceptance traceability.

---

# 5. Implementation Activities

```text
Collect approved requirements
Assign requirement IDs
Map requirements to capabilities
Map capabilities to test cases
Map test cases to execution results
Map defects to requirements
Map defects to test cases
Record test evidence
Record UAT acceptance
Identify untested requirements
Resolve traceability gaps
Produce traceability report
```
