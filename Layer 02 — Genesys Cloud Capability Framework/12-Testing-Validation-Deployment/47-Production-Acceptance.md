# 47 — Production Acceptance

## Capability Definition

Provides formal business and technical acceptance that the deployed Genesys Cloud solution is operating as required.

---

# 1. Scope

- Technical acceptance
- Business acceptance
- Operational acceptance
- UAT
- Production validation
- Residual risks
- Outstanding defects

---

# 2. Classification

**Required**

---

# 3. Discovery Activities

- Identify acceptance authorities.
- Review acceptance criteria.
- Review outstanding defects.
- Review residual risks.
- Review operational performance.

---

# 4. Design Activities

- Define acceptance package.
- Define acceptance thresholds.
- Define residual-risk process.
- Define approval workflow.

---

# 5. Implementation Activities

```text
Compile test results
Compile UAT results
Compile production validation
Review defects
Review residual risks
Review operational readiness
Review business performance
Prepare acceptance pack
Conduct acceptance review
Resolve open questions
Obtain business acceptance
Obtain technical acceptance
Record formal acceptance
```
