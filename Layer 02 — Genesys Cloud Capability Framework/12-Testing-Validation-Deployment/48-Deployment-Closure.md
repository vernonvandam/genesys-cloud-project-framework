# 48 — Deployment Closure

## Capability Definition

Closes the deployment workstream after production implementation, validation, acceptance, documentation and transition activities have been completed.

---

# 1. Scope

- Deployment records
- Outstanding issues
- Documentation
- Handover
- Acceptance
- Lessons learned
- Project closure

---

# 2. Classification

**Required**

---

# 3. Discovery Activities

- Identify closure requirements.
- Identify outstanding deployment activities.
- Identify open issues.
- Identify required documentation.

---

# 4. Design Activities

- Define closure checklist.
- Define documentation handover.
- Define outstanding-work process.
- Define acceptance process.

---

# 5. Implementation Activities

```text
Complete deployment record
Close deployment issues
Complete documentation
Complete operational handover
Confirm support ownership
Confirm production acceptance
Review outstanding work
Transfer remaining backlog
Complete lessons learned
Archive project evidence
Complete closure checklist
Obtain closure approval
```

---

# 6. Dependencies

- Production Acceptance
- Operational Handover
- Hypercare
- Lessons Learned

---

# 7. Layer 1 Mapping

Primary:

- Phase 12 — Project Closure & Handover

Supporting:

- Phase 11 — Hypercare & Stabilisation

---

# 8. Roles

- Project Manager
- Service Manager
- Solution Architect
- Customer Product Owner
- Operations Lead

---

# 9. Customer Responsibilities

- Accept handover.
- Confirm BAU ownership.
- Approve closure.
- Accept remaining backlog.

---

# 10. Testing

Confirm all mandatory test evidence has been archived.

---

# 11. Deliverables

- Deployment Closure Report
- Handover Pack
- Final Issue Register
- Project Evidence Archive
- Closure Checklist

---

# 12. Effort Drivers

- Project size
- Documentation volume
- Outstanding issues
- Number of stakeholders

---

# 13. Acceptance Criteria

- Deployment complete.
- Handover complete.
- Acceptance obtained.
- Outstanding work transferred.
- Evidence archived.

---

# 14. Definition of Done

Deployment is formally closed and transferred to BAU.
