# 02 — Test Governance

## Capability Definition

Defines the governance model used to control testing, approve test stages, manage risks, review defects and determine whether the solution can progress through the deployment lifecycle.

---

# 1. Scope

- Test governance structure
- Test decision authority
- Test reporting
- Test status meetings
- Quality gates
- Defect governance
- Risk governance
- Test approvals
- Escalation

---

# 2. Classification

**Required**

---

- Identify project governance structure.
- Identify customer approval authorities.
- Identify testing stakeholders.
- Identify reporting requirements.
- Identify decision-making authority.
- Identify escalation paths.
- Identify required quality gates.

# 4. Design Activities

- Define test governance structure.

- Define quality gates.

- Define risk escalation thresholds.
